Deck SMPTE 輸出 輸出 Set list 混音器 Cue call
下載 Mac 版 下載 Windows 版

將 CDJ 與 DJM 的資料以 TCNet、SMPTE 時間碼、OSC、DMX 與 MIDI 送出。

下載 Mac 版 下載 Windows 版

版本 2.0.3，免費 Beta 版。Apple Silicon 上的 macOS 13.3 以上、Windows 10 與 11。

網路上的每一台 deck。

每台播放器的位置、BPM、波形與 cue，完全依照播放器送出的資料。

以時間碼輸出。

layer A、B 與 MASTER 的 LTC、MTC 與 Art-Net 時間碼。

送到每個接收端。

節點編輯器，將 deck 與混音器的數值轉成 OSC、Art-Net 或 sACN 的 DMX，以及 MIDI。

每個瞬間都有一個 cue。

每首曲目各有時間碼偏移，cue 對準拍點送出 OSC、DMX 與 MIDI。

混音器的一舉一動。

DJM 回報的推桿、EQ、FX 與電平表，畫面為 DJM-900NXS2。

工作人員聽得見的 cue call。

各群組的下一個 cue 與剩餘時間、語音播報，以及手機上 /cuecall 的同一個倒數。

相容設備與環境

已測試的設備
CDJ-3000X, CDJ-3000, CDJ-2000NXS2, DJM-V10, DJM-900NXS2
送出
TCNet、LTC、MTC、Art-Net 時間碼、OSC、DMX (Art-Net、sACN)、MIDI
接收
鍵盤、MIDI、OSC (UDP 7700)、Art-Net DMX (UDP 6454)
作業系統
Apple Silicon 上的 macOS 13.3 以上、Windows 10 與 11 (x64)
網際網路
不傳送使用資料。檢查更新時會以 App 版本向 GitHub 查詢，且可以關閉。

其他設備尚未測試。歡迎在 Issues 回報結果。
