CDJ と DJM のデータを TCNet、SMPTE タイムコード、OSC、DMX、MIDI として送信します。

Mac 版をダウンロード Windows 版をダウンロード

バージョン 2.0.3、無料ベータ版。Apple シリコン搭載 Mac の macOS 13.3 以降、Windows 10 / 11。

リンク上の全デッキを一画面に。

すべてのプレーヤーの再生位置、BPM、波形、キューを、プレーヤーが送るとおりに表示。

タイムコードとして出力。

レイヤー A、B、MASTER の LTC、MTC、Art-Net タイムコード。

あらゆる受信機器へ。

デッキとミキサーの値を OSC、Art-Net または sACN の DMX、MIDI に変換するノードエディター。

すべての瞬間にキューを。

曲ごとにタイムコードオフセットを設定し、キューが拍に合わせて OSC、DMX、MIDI を送信します。

ミキサーの動きをそのままに。

DJM が伝えるフェーダー、EQ、FX、レベルメーター。画面は DJM-900NXS2。

スタッフの耳に届くキューコール。

グループごとの次のキューと残り時間、音声コール。同じカウントダウンはスマートフォンの /cuecall でも。

対応機器と環境

テスト済みの機器
CDJ-3000X, CDJ-3000, CDJ-2000NXS2, DJM-V10, DJM-900NXS2
送信
TCNet、LTC、MTC、Art-Net タイムコード、OSC、DMX (Art-Net、sACN)、MIDI
受信
キーボード、MIDI、OSC (UDP 7700)、Art-Net DMX (UDP 6454)
動作環境
Apple シリコン搭載 Mac の macOS 13.3 以降、Windows 10 / 11 (x64)
インターネット
使用データは送信しません。アップデート確認はアプリのバージョンを添えて GitHub に問い合わせるもので、オフにできます。

その他の機器はまだテストしていません。結果は Issues でお知らせください。
