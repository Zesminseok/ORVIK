## 1. 시작하기 전에

### ORVIK은

ORVIK은 CDJ, DJM의 재생 정보를 받아 조명, 영상 프로그램으로 보내는 앱입니다. TCNet, SMPTE 타임코드(LTC, MTC, Art-Net), OSC, DMX(Art-Net, sACN), MIDI로 내보냅니다. 장비에는 정보를 요청하기만 하며 제어하지 않습니다.

### 사용 환경

| 항목 | 내용 |
| --- | --- |
| 운영체제 | macOS 13.3 이상(Apple Silicon), Windows 10, 11(x64) |
| 확인한 장비 | CDJ-3000X, CDJ-3000, CDJ-2000NXS2, DJM-V10, DJM-900NXS2 |

장비, 펌웨어, 연결 구성에 따라 받을 수 있는 정보가 다릅니다.

### 설치와 실행

- **macOS** — DMG를 열어 ORVIK을 응용 프로그램 폴더로 옮깁니다.
- **Windows** — 받은 `.exe`를 바로 실행합니다. 설치 과정이 없습니다. 코드 서명이 없어 처음 실행할 때 SmartScreen 경고가 뜨면 "추가 정보"에서 실행을 고릅니다.

켤 때와 끌 때 짧은 스플래시 화면이 나옵니다. 끌 때는 TCNet과 PRO DJ LINK 연결을 정리한 뒤 닫힙니다.

## 3. 헤더

![헤더](images/02-header.png)

1. **MASTER BPM** — CDJ 마스터의 BPM입니다. CDJ 마스터에 BPM이 없으면 재생 중인 덱의 BPM이 나오며, 온에어인 덱을 먼저 씁니다. 왼쪽 칸은 CDJ 마스터의 플레이어 번호입니다.
2. **PRO DJ LINK** — CDJ, DJM 연결을 켜고 끕니다.
3. **TCNET** — 조명, 영상 프로그램으로 보내는 TCNet 송출을 켜고 끕니다. 설정의 TCNet 모드가 Client이거나 STANDBY 상태이면 켜져 있어도 송출하지 않습니다.
4. **CUE CALL** — 큐 콜 창을 엽니다. [11장](#11-cue-call)
5. **새로고침** — 화면을 다시 불러옵니다(Cmd/Ctrl+R). 가상 덱 재생은 멈춥니다.
6. **M.VOL** — 앱이 출력하는 가상 덱 소리의 볼륨입니다. CDJ, 믹서 소리에는 영향이 없습니다.
7. **창 버튼** — Windows에서 창을 최소화, 최대화하고 ORVIK을 종료합니다. macOS에서는 창 왼쪽 위의 기본 버튼을 씁니다. 저장하지 않은 히스토리나 셋리스트가 있으면 종료할 때 저장할지 묻습니다.

### 스위치 상태

PRO DJ LINK, TCNET 스위치는 켜지면 왼쪽 칸이 상태 색으로 채워집니다. 정상이면 초록이고, 켜는 동안에는 점이 깜빡입니다. 확인할 일이 있으면 스위치 안에 아래 표시가 붙습니다.

| 표시 | 뜻 |
| --- | --- |
| NO H/W | PRO DJ LINK는 켜져 있지만 CDJ, DJM이 보이지 않습니다. |
| LOST | 하드웨어 덱은 있지만 어느 CDJ에서도 1.5초 넘게 상태가 들어오지 않습니다. |
| STANDBY | 같은 네트워크에 먼저 켜진 TCNet 서버가 있어 송출을 멈추고 기다리는 중입니다. |

새 버전이 나오면 헤더에 UPDATE 표시가 나타납니다. 누르면 다운로드 페이지를 엽니다.

## 5. 상태 바

![상태 바](images/05-status-bar.png)

1. **TCNET** — 헤더의 TCNET 스위치가 켜져 있는지 나타냅니다. STANDBY일 때는 ON이어도 송출하지 않습니다.
2. **ARENA** — 최근 10초 안에 확인된 TCNet 노드 수입니다.
3. **DECKS** — 하드웨어 덱과, 곡이 올라간 가상 덱을 더한 수입니다.
4. **UP** — 엔진이 켜진 뒤 지난 시간입니다.
5. **CPU** — ORVIK의 CPU 사용률입니다.
6. **MEM** — ORVIK이 쓰는 메모리 양입니다.
7. **덱 점** — 덱마다 점 하나입니다. 하드웨어 덱은 하드웨어 색으로, 가상 덱은 재생, 큐, 곡 있음, 빈 덱에 따라 다른 색으로 나옵니다.

문제가 생기면 상태 바에 LINK, OUT, MIX 표시가 나타납니다. LINK는 플레이어 번호가 겹칠 때, OUT은 TCNet 송출이 멈췄거나 미러 상태일 때, MIX는 믹서 데이터가 끊겼을 때 켜집니다. 누르면 관련 페이지로 이동하며, 문제가 없으면 나타나지 않습니다.

## 6. DECKS

### 6.1 덱 모드와 연결 기기

![덱 모드와 연결 기기](images/03-deck-top.png)

1. **덱 모드** — HARDWARE는 PRO DJ LINK 네트워크의 CDJ를 따라갑니다(기본). VIRTUAL은 컴퓨터의 오디오 파일을 재생하는 가상 덱을 씁니다. 모드를 바꾸면 지금 덱이 사라지며, 가상 덱이 있을 때 HARDWARE로 바꾸면 먼저 확인을 받습니다. [6.4](#64-가상-덱)
2. **CDJ** — 연결된 플레이어의 번호와 기종입니다. 마우스를 올리면 IP 주소가 보이고, 우클릭하면 덱 색을 고릅니다.
3. **DJM** — 연결된 믹서의 기종입니다. 믹서 조작 값이 1.5초 넘게 들어오지 않으면 NO DATA가 붙습니다.

### 6.2 덱 카드

![덱 카드](images/04-deck-card.png)

그림은 FLOW 레이아웃의 덱 카드입니다. 레이아웃에 따라 일부 요소가 빠지거나 자리가 바뀝니다.

1. **플레이어 번호** — 우클릭하면 덱 색을 고릅니다.
2. **곡 제목, 아티스트**
3. **키** — 곡의 키입니다. 8A 같은 카멜롯 표기로 바꿔 나오며, 바꿀 수 없는 키는 원래 값 그대로 나옵니다.
4. **ON AIR** — 믹서에서 이 덱의 채널이 온에어일 때 켜집니다.
5. **MASTER** — 이 덱이 CDJ 마스터일 때 켜집니다.
6. **SYNC** — Beat Sync가 켜져 있을 때 켜집니다.
7. **채널 페이더, 레벨 인디케이터** — DJM의 채널 페이더 위치와 채널 레벨입니다.
8. **재생 상태** — PLAY, PAUSE, CUE, LOOP 등입니다.
9. **기종, 미디어** — CDJ 기종과, 곡이 든 미디어(플레이어 번호와 USB, SD)입니다. 미디어 칩의 색은 rekordbox에서 정한 미디어 색이고, 색을 정하지 않은 미디어는 회색입니다. 색 정보가 없으면 칩 대신 글자로 나옵니다.
10. **크게 고정** — FLOW 레이아웃에서 이 덱을 크게 고정합니다. 다시 누르거나 곡이 바뀌면 풀립니다.
11. **디테일 웨이브폼** — 재생 위치 주변의 파형입니다. 빨간 선이 재생 위치입니다.
12. **마디 카운터** — 다음 메모리 큐까지 남은 마디입니다. 8마디 이하가 되면 빨갛게 바뀌고, 앞에 메모리 큐가 없으면 지난 마디가 나옵니다. 누르면 초 단위로 바뀝니다.
13. **줌** — −로 파형을 넓게(누를 때마다 2배), +로 좁게(최소 0.5초) 봅니다. RST는 기본 8초로 되돌립니다.
14. **오버뷰 웨이브폼** — 곡 전체의 파형입니다. 하드웨어 덱에서는 누르고 있는 동안 그 자리의 디테일 웨이브폼을 미리 보여 주고, 손을 떼면 돌아옵니다. 미리 보는 동안 마디 카운터에는 재생 위치와의 차이가 초나 분:초로 나옵니다.
15. **타임코드** — 지금 재생 위치의 타임코드입니다.
16. **시간** — 누르면 지난 시간과 남은 시간이 바뀝니다. 오른쪽은 곡 길이입니다.
17. **비트 위치** — 마디 안에서 지금 몇 번째 비트인지 보여 줍니다.
18. **BPM** — 왼쪽 위는 곡의 원래 BPM, 그 아래는 템포 변경(%), 오른쪽 큰 숫자는 지금 BPM입니다.
19. **SMPTE MASTER** — 이 덱을 레이어 A나 B에 배정하고, 그 레이어를 MASTER의 소스로 정합니다. 다시 누르면 MASTER 소스만 풀리고 A, B 배정은 남습니다. LTC, MTC, Art-Net 출력은 SMPTE OUT에서 따로 켭니다.
20. **SMPTE A, B** — 이 덱을 SMPTE 레이어 A 또는 B의 소스로 정합니다.

웨이브폼 색을 3밴드로 골랐는데 곡에 3밴드 데이터가 없으면 덱에 ! 표시가 붙고 RGB로 나옵니다. 웨이브폼은 그래픽 카드(GPU)로 그립니다.

### 6.4 가상 덱

![가상 덱](images/07-virtual-deck.png)

덱 모드를 VIRTUAL로 바꾸면 컴퓨터의 오디오 파일을 재생하는 가상 덱을 씁니다. 그림은 STK 레이아웃입니다. 재생 버튼(⑧)은 STRIP을 뺀 모든 레이아웃에 있고, FLOW에서는 타임코드와 BPM 사이에 나옵니다.

1. **덱 번호**
2. **VIRTUAL, LOCAL** — 가상 덱이고 곡이 이 컴퓨터의 파일이라는 표시입니다.
3. **×** — 이 가상 덱을 지웁니다.
4. **채널 페이더** — 끌어서 조절합니다.
5. **앨범아트** — 누르면 곡을 내립니다.
6. **디테일 웨이브폼** — 끌면 재생 위치를 앞뒤로 옮깁니다.
7. **오버뷰 웨이브폼** — 누르거나 끌어서 재생 위치를 옮깁니다.
8. **|◀, CUE, ▶** — CUE는 멈춘 상태에서 누르면 그 자리를 큐 지점으로 정하고 누르는 동안 들려 줍니다. 재생 중에 누르면 큐 지점으로 돌아갑니다. ▶는 재생, 일시정지, |◀는 멈추고 곡 처음으로 돌아갑니다.
9. **열기** — 눌러서 오디오 파일을 고르거나 파일을 여기로 끌어다 놓습니다.
10. **가상 덱 추가** — 가상 덱을 하나 더합니다. 최대 6개입니다.

열 수 있는 파일은 MP3, WAV, AIFF, FLAC, AAC, M4A(AAC, ALAC), OGG, MP4(오디오)입니다. CDJ가 여는 형식은 모두 열립니다.

가상 덱 소리는 [설정](#15-설정)의 **오디오 출력**에서 고른 장치로 나오며 볼륨은 헤더의 M.VOL로 조절합니다.

## 7. SMPTE OUT

![SMPTE OUT](images/06-smpte-dock.png)

타임코드 출력 레이어는 A, B, MASTER 세 개입니다. 레이어 A, B는 고른 덱의 재생 위치를, MASTER는 A, B 레이어나 컴퓨터 시각, FREEWHEEL 가운데 하나를 타임코드로 냅니다. 그림은 레이어 A와 MASTER이며 레이어 B는 A와 같습니다.

1. **SMPTE OUT** — 눌러서 도크를 펼치거나 접습니다. 접혀 있을 때는 레이어마다 연결된 소스와 켜진 출력을 요약해 보여 줍니다.
2. **따로 열기** — SMPTE OUT을 따로 창으로 엽니다. 창을 닫으면 도크로 돌아옵니다.
3. **레이어 A** — 고른 덱의 재생 위치를 타임코드로 내는 레이어입니다. 레이어 B도 같습니다.
4. **LTC, MTC, ART** — 이 레이어의 LTC(오디오 타임코드), MTC(MIDI 타임코드), ART(Art-Net 타임코드) 출력을 켜고 끕니다. LTC와 ART는 레이어마다 켤 수 있고, MTC는 한 레이어만 켤 수 있습니다. LTC 장치와 MTC 포트는 [설정](#15-설정)의 **SMPTE Timecode 출력**에서, Art-Net 네트워크와 프레임 레이트는 [OUTPUT](#13-output) 페이지 위쪽에서 고릅니다.
5. **소스 덱** — 이 레이어가 따라갈 덱을 고릅니다. 덱 카드의 A, B 버튼과 같습니다.
6. **타임코드** — 소스 위치에 오프셋을 더한 타임코드입니다. 실제 송출에는 설정의 레이턴시 보정이 더해집니다.
7. **− / +** — 각 자리의 값을 1씩 바꿉니다. Ctrl(맥은 Cmd)을 누른 채 누르면 10씩 바꿉니다. MASTER의 STEP이 TIME이면 FREEWHEEL 시간을, 그 밖에는 오프셋을 바꿉니다.
8. **SET** — 셋리스트의 오프셋이 이 레이어에 들어가 있다는 표시입니다. 마우스를 올리면 곡 이름이 보입니다. 목록에 없는 곡이라 UNLISTED 오프셋이 들어가면 SET —로 나옵니다.
9. **OFFSET ON** — 오프셋을 송출에 넣거나 뺍니다. 값은 그대로 둡니다.
10. **되돌리기** — 오프셋을 0으로 되돌립니다.
11. **MASTER** — MASTER 레이어입니다.
12. **FREEWHEEL 버튼** — ▶는 FREEWHEEL 타임코드를 흐르게 하고, ❚❚는 값을 둔 채 멈춥니다. |◀는 00:00:00:00으로 되돌립니다. READY(◉)를 누르면 FREEWHEEL이 지금 값에서 멈추고 기다리다가, 덱이 새로 재생을 시작할 때 출발합니다. 믹서가 있으면 그 순간 온에어인 덱만 세고, 이미 재생 중이던 덱과 CUE로 미리 듣는 것은 세지 않습니다.
13. **소스** — A, B는 그 레이어의 타임코드에 MASTER 오프셋을 더해 냅니다. CLOCK은 컴퓨터 시각을 쓰고, FREEWHEEL은 직전 MASTER 값에서 이어서 혼자 흐릅니다.
14. **STEP** — MASTER 소스가 FREEWHEEL일 때, − / + 버튼이 오프셋(OFS)을 바꿀지 FREEWHEEL 시간(TIME)을 바꿀지 고릅니다.

덱이 멈춰 있어도 LTC는 멈춘 위치의 타임코드를 계속 냅니다. 받는 쪽이 멈춤을 알 수 있도록 같은 프레임이 반복됩니다.

## 9. HISTORY

![HISTORY](images/14-history.png)

온에어로 나간 곡을 실제 시각과 덱 번호로 기록합니다. 믹서가 있으면 재생 중이면서 온에어인 시간을, 없으면 재생 중인 시간을 세어 10초 이상이면 기록합니다. 재생이나 온에어가 3초 넘게 끊겼다가 다시 시작되면 같은 곡이라도 새 줄로 기록하고 3초 안에 돌아오면 한 줄로 이어집니다. 가상 덱은 곡을 올리면 바로 기록하고 재생한 시간을 셉니다. 지금 나가는 곡은 END 자리에 LIVE가 표시됩니다.

기록은 ORVIK을 켤 때마다 새로 시작합니다. 기록은 자동으로 저장되며, ORVIK이 비정상적으로 종료됐다면 다음에 켤 때 이어서 쓸지 묻습니다.

1. **시작 시각** — 이번 기록을 시작한 날짜와 시각입니다.
2. **곡 수** — 기록된 곡 수입니다.
3. **IMPORT** — 히스토리 파일(ORVIK CSV, ShowKontrol 히스토리 CSV, TXT)을 불러와 지금 기록에 합칩니다. 파일의 기록은 고치거나 빼지 않고 그대로 넣습니다.
4. **EXPORT** — 형식을 골라 저장합니다. ORVIK CSV(ORVIK으로 다시 불러올 수 있음), ShowKontrol 히스토리, ShowKontrol 셋리스트, 트랙리스트 TXT 가운데 고릅니다.
5. **CLEAR** — 기록을 모두 지웁니다. 3초 안에 한 번 더 눌러야 지워집니다.
6. **EVENT** — 행사 이름입니다. 내보내는 파일 이름(ORVIK CSV, 셋리스트, 트랙리스트)과 트랙리스트 TXT 본문에 들어갑니다.
7. **DJ** — DJ 이름입니다. 트랙리스트 TXT 본문에 들어갑니다.
8. **검색** — 제목이나 아티스트로 찾습니다.
9. **표 머리** — 경계를 끌어 열 너비를 바꾸고 두 번 누르면 원래대로 돌아갑니다. 열은 다음과 같습니다.
   - **DECK** — 곡이 나간 플레이어 번호와 기종입니다.
   - **START, END** — 온에어가 시작된 시각과 끝난 시각입니다.
   - **IN, OUT** — 온에어가 시작될 때와 끝날 때의 재생 위치입니다.
   - **ON AIR** — 온에어로 나간 시간입니다.
10. **합계** — 재생 곡 수, 총 ON AIR 시간, 평균 BPM, 덱별 곡 수입니다.

행에 마우스를 올리면 오른쪽 끝에 셋리스트에 추가하는 버튼과 지우기 버튼이 나옵니다. 지금 나가는 곡을 지우면 그 곡이 재생되는 동안은 다시 기록하지 않습니다.

## 10. SET LIST

![SET LIST](images/15-setlist.png)

곡마다 타임코드 오프셋과 큐를 정해 두는 목록입니다. APPLY TO SMPTE를 켜 두면, 목록에 있는 곡이 덱에 올라올 때 그 덱이 연결된 SMPTE 레이어(A, B)에 곡의 오프셋이 들어갑니다. 셋리스트도 히스토리처럼 ORVIK을 켤 때마다 비워지고, 자동 저장과 복구 안내는 히스토리와 같습니다.

1. **곡 수** — 목록의 곡 수입니다.
2. **APPLY TO SMPTE** — 켜면 덱에 올라온 곡의 오프셋을 그 덱이 연결된 레이어에 넣습니다. 끄면 레이어 오프셋을 그대로 둡니다.
3. **UNLISTED** — 목록에 없는 곡에 쓸 오프셋입니다. 옆 버튼은 00:00:00:00으로 되돌립니다.
4. **AUTO FILL** — 시작 값과 간격(1H, 30M, 10M)을 정하고 FILL을 누르면 목록 순서대로 오프셋을 채웁니다. 간격을 고르지 않으면 모두 같은 값으로 채웁니다.
5. **ADD** — +로 곡을 직접 입력해 더하고, 덱 번호로 그 덱에 올라온 곡을 더합니다.
6. **검색** — 제목이나 아티스트로 찾습니다.
7. **IMPORT** — 셋리스트를 불러옵니다. ORVIK 파일, ShowKontrol 셋리스트(.set), 히스토리(.csv), rekordbox 등에서 내보낸 텍스트 플레이리스트, 음원 파일을 열 수 있습니다. 목록이 있으면 바꿀지(REPLACE) 뒤에 붙일지(ADD) 묻고 텍스트 파일의 열을 알아보지 못하면 열을 고르게 합니다. ORVIK 파일에는 큐도 함께 들어 있습니다.
8. **EXPORT** — 형식을 골라 저장합니다. ORVIK 파일이나 ShowKontrol 셋리스트(.set)로 저장합니다.
9. **CLEAR PLAYED** — 재생됨 표시만 지웁니다.
10. **CLEAR** — 목록을 모두 지웁니다. 3초 안에 한 번 더 눌러야 지워집니다. 곡의 큐도 함께 지워집니다.
11. **OFFSET** — 이 곡의 오프셋입니다. 곡이 덱에 올라오면 이 값이 레이어에 들어갑니다. 누르면 고치고, 옆 버튼은 00:00:00:00으로 되돌립니다.
12. **STATUS (덱에 있음)** — 곡이 올라온 덱 번호와, 오프셋이 들어간 레이어(A, B)입니다.
13. **STATUS (재생됨)** — APPLY TO SMPTE가 켜진 동안 이 곡이 재생되고 온에어로 나가면 체크가 붙습니다. 믹서가 없으면 재생만 봅니다. 같은 곡이 목록에 여러 번 있으면 아직 체크가 없는 줄의 오프셋을 쓰고 한 번만 있으면 다시 틀어도 그 줄의 오프셋을 씁니다.
14. **덱에 있는 곡** — 지금 덱에 올라와 있는 곡은 행이 강조됩니다.

제목, 아티스트는 누르면 고칠 수 있습니다. 행 오른쪽 버튼으로 곡을 한 칸 위, 아래로 옮기거나 목록에서 지웁니다. 표 머리의 경계를 끌면 열 너비가 바뀌고 두 번 누르면 원래대로 돌아갑니다. 곡 줄의 **웨이브폼** 칸은 큐 편집에 쓸 파형의 출처(음원, HISTORY, CDJ, 없음)이고 **큐** 칸은 그 곡의 큐 개수입니다.

### 10.1 큐 편집

큐 편집기는 SET LIST 페이지 오른쪽에 열립니다. 곡을 고르면 그 곡의 파형과 큐 목록이 나옵니다.

- **파형** — 곡 전체 파형과 확대 파형입니다. 비트 그리드, 마디 번호, 프레이즈 띠, 큐 표시가 그려집니다. 파형은 음원 파일, HISTORY의 기록, CDJ에서 받은 파형 가운데 있는 것을 씁니다. CDJ 파형을 쓰려면 트랙 라이브러리를 켜 둡니다(편집기의 안내에서 켤 수 있습니다). 파형이 없어도 시간만으로 큐를 넣을 수 있습니다.
- **위치 옮기기** — 파형을 누르면 편집 위치가 옮겨집니다. **스냅**(끔, 박, 마디, 프레임)으로 위치를 눈금에 맞춥니다. **줌**으로 확대 파형의 범위를 바꿉니다.
- **+ 큐 (C)** — 편집 위치에 큐를 만듭니다. 음원이 있으면 그 자리를 미리 들려 줍니다.
- **핫큐 가져오기** — rekordbox 핫큐와 메모리 포인트를 큐 위치로 가져옵니다.
- **큐 목록** — 시간, 마디.박, 이름, 그룹, 동작 요약입니다.
- **큐 설정** — 고른 큐의 이름, 시간, 마디.박, 그룹, 미리 알림(기본값 따름 또는 박 수), 음성(그룹 따름, 켜기, 끄기), 말할 내용(비우면 큐 이름을 말함), 동작 목록입니다.
- **동작 목록** — 위에서부터 차례로 실행합니다. OSC(보내는 곳, 주소, 형식 i/f/s, 값), Art-Net DMX(유니버스, 채널=값 여러 개), MIDI(장치, 채널, Note on/off, CC, Program), 대기(ms 또는 박, 마디)를 둘 수 있습니다. 보내는 곳 목록은 OUTPUT 페이지와 같습니다.
- **그룹** — 큐의 담당 그룹입니다. 기본 그룹은 조명, 영상, 특효, 레이저이고, 그룹 메뉴의 **그룹 편집…**에서 이름과 색을 바꾸거나 더합니다. 그룹은 큐 콜 창의 표시와 음성 출력에 쓰입니다.
- **큐 출력** — 편집기 위의 스위치로 큐 동작 송출을 켜고 끕니다.

큐는 마스터 덱에서 재생 중인 곡에만 반응합니다. 마스터 덱의 곡이 셋리스트에 없으면 큐를 내보내지 않습니다. 큐는 곡의 비트 그리드와 재생 위치로 박을 계산해 그 박에 내보냅니다. 큐는 셋리스트 항목에 붙어 있어, 같은 곡이라도 셋리스트마다 큐가 따로입니다.

## 11. CUE CALL

헤더의 CUE CALL 버튼으로 큐 콜 창을 엽니다. 마스터 덱에서 재생 중인 곡의 큐를 그룹별로 보여 주고, 다음 큐까지 남은 시간을 셉니다. 창은 여러 개 띄울 수 있고(예: 조명 담당, 특효 담당), 위치와 크기, 표시 설정은 창마다 기억합니다. 창 제목줄의 버튼으로 메인 창 오른쪽에 붙이거나 다시 뗍니다.

### 테마

- **보드** — 그룹마다 타일 하나입니다. 큐 이름, 다음 큐, 큰 카운트다운, 마지막 8마디의 진행 막대가 있습니다. 큐에 가까워지면 타일이 그룹 색으로 차오르고, 큐 순간에 GO가 뜹니다.
- **레이어** — 흐르는 타임라인입니다. 위에는 마스터 덱의 파형과 큐 마크, 아래에는 그룹별 줄과 다음 곡 줄이 있습니다. NOW 선은 폭의 20% 자리이고, 큐는 NOW에 닿는 순간 나갑니다.

### 남은 시간

초와 박(마디.박, CDJ 비트 카운트다운 방식)을 같이 보여 줍니다. `2.3`은 2마디 3박 남았다는 뜻입니다. 큰 카운트다운에 들어가면 초가 0.1초 단위로 그룹 색이 되고, 마지막 박은 3 2 1(또는 5, 10부터)로 세고 GO가 뜹니다. 숫자를 누르면 초 우선, 박 우선, 초만 사이를 바로 바꿉니다.

### 설정 팝업 (톱니바퀴)

| 구역 | 항목 |
| --- | --- |
| 표시 | 남은 시간 표시(초 우선, 박 우선, 초만), 큰 카운트다운(5, 10, 15, 30초), 박 카운트 시작(3, 5, 10), 타임라인 범위, 표시 그룹, 웨이브폼 색(곡 색, 그룹 색, 회색) |
| 웹뷰 | 폰, 태블릿에서 열 주소와 **주소 복사**, **브라우저로 열기**. 설정의 웹 뷰어가 켜져 있어야 합니다. |
| 음성 | 말하는 방식(이름+카운트, 이름만, 카운트만), 미리 알림(8박 전, 4박 전), 카운트다운(3, 2, 1 또는 없음), 마지막 말(켬, 끔), 목소리, 클릭(없음, 카운트 중, 항상)과 볼륨, 출력(장치, 채널, 볼륨, 들어 보기), 그룹별 음소거 |

### 음성 안내

큐 콜 창 헤더의 스피커로 음성 안내를 켜고 끕니다. 시스템 목소리(macOS, Windows)로 문장을 미리 만들어 두고, 공연 중에는 박에 맞춰 재생합니다.

- 큐 8박(또는 4박) 전에 "그룹, 큐 이름, 스탠바이", 박마다 "셋, 둘, 하나", 큐 순간에 "고"를 말합니다.
- **목소리** 목록은 앱이 말할 수 있는 언어(한국어, 영어, 일본어, 스페인어, 독일어, 프랑스어, 중국어)의 목소리만 언어별로 묶어 보여 줍니다. 첫 줄 "시스템 ○○ 목소리"는 화면 언어의 기본 목소리입니다. 다른 언어의 목소리를 고르면 안내도 그 언어로 바뀝니다(영어 목소리면 "Lighting, standby", "three, two, one, go"). 셋리스트에서 직접 지은 그룹 이름은 그대로 읽습니다.
- 그 언어의 목소리가 없으면 영어로 말하고 목록 첫 줄에 안내가 나옵니다. 목소리는 운영체제의 음성 설정에서 더할 수 있습니다.
- **출력**은 LTC와 같은 오디오 장치의 다른 채널을 고를 수 있지만, LTC가 쓰는 채널은 고를 수 없습니다. 같은 채널을 고르면 설정에 충돌 안내가 나옵니다.
- 그룹 이름 옆 스피커로 그 그룹만 끕니다. 창에서 숨긴 그룹은 말하지 않습니다.

### 웹 페이지

설정의 웹 뷰어가 켜져 있으면 같은 네트워크의 폰, 태블릿, 다른 컴퓨터에서 `http://<이 컴퓨터 주소>:<포트>/cuecall`을 엽니다. 처음에는 접속 코드를 묻고(웹 뷰어와 같은 코드), 12시간 동안 기억합니다. 보드, 레이어 테마와 표시 설정은 그 기기에서 따로 고릅니다. 폰 세로 화면에 맞춘 배치가 있습니다.

## 13. OUTPUT

덱, 믹서 값을 OSC, DMX(Art-Net, sACN), MIDI로 다른 프로그램과 장비에 보냅니다. 예전의 OSC 페이지와 ART-NET DMX 패치를 하나로 합친 노드 편집기입니다. 1.6에서 쓰던 OSC 줄과 DMX 패치는 처음 켤 때 노드로 옮겨지며 보내는 값은 같습니다.

### 페이지 위쪽

- **IMPORT, EXPORT** — 노드 그래프를 파일로 저장하거나 불러옵니다.
- **OSC** — OSC를 보낼 곳(주소:포트)입니다. 이 컴퓨터, IP 주소, 브로드캐스트 가운데 고릅니다.
- **Art-Net 네트워크** — Art-Net을 내보낼 네트워크 인터페이스와 DMX 송출 빈도(Hz)입니다.
- **Art-Net 타임코드** — Art-Net 타임코드의 프레임 레이트입니다. 레이어별 켜기는 SMPTE OUT의 ART 버튼입니다.
- **MIDI** — MIDI를 보낼 장치입니다.
- **스캔** — Art-Net 장비(ArtPoll)와 MIDI 장치를 다시 찾습니다.

### 왼쪽 목록

누르면 가운데 캔버스에 노드가 생깁니다.

| 묶음 | 노드 |
| --- | --- |
| 보내는 곳 | OSC, DMX 출력, MIDI CC, MIDI Note |
| 값 (믹서 채널 1~6) | Fader, VU, Hi, Mid, LoMid, Low, Color, OnAir |
| 값 (믹서 전체, 이펙터) | Xf, MVU, MVUL, MVUR, BeatFX, BeatFXOn, BeatFXName, BeatFXCh, ColorFXName |
| 값 (덱 템포) | BPM, BPMCoarse, BPMFine, Beat, Downbeat, Phase, BarBeat, BarPhase |
| 값 (덱 시간, 프레이즈) | Pos, Time, Length, Remain, Phrase, PhraseKind, PhrasePos, PhraseBeats |
| 값 (덱 상태, 트랙) | Loop, Sync, Master, CDJPlay, CDJCue, Deck, Title, Artist, Key |
| 값 (SMPTE 출력) | SMPTEA, SMPTEB, SMPTEM, Clock |
| 변환 | 범위, 모양(sin, tri, saw, sq), 반전, 프리런, 시간 형식 |
| 연산 | 더하기, 빼기, 곱하기, 나누기, 최솟값, 최댓값, 부드럽게, 줄바꿈 |

### 가운데 캔버스와 오른쪽 설정

값 노드의 출력을 끌어 변환, 연산, 보내는 곳 노드의 입력에 잇습니다. 선 위에는 지금 흐르는 값이 보입니다. 값 하나를 여러 곳으로 보낼 수 있습니다. 노드를 고르면 오른쪽에 설정(덱 선택, 범위, 주소, 채널, 형식, 지금 값)이 나옵니다. 값 노드의 덱은 마스터 덱 따라감 또는 덱 1~6입니다.

- **OSC** — 주소와 형식(int, float, string)입니다. 값이 바뀔 때만 보내며 최대 60Hz입니다. 주소에 `/`가 없으면 붙이고, 공백과 `# * , ? [ ] { }`는 쓸 수 없습니다.
- **DMX 출력** — Net, Subnet, Universe와 채널입니다. 0~1 값을 0~255로 보냅니다. 받을 곳(유니캐스트 IP 또는 브로드캐스트)과 sACN 우선순위는 노드 설정에서 정합니다.
- **MIDI CC, MIDI Note** — 채널과 CC 번호 또는 노트 번호입니다. 0~1 값을 0~127로 보냅니다.
- **범위** — 0~1 값을 최소~최대로 바꿉니다. 최소를 더 크게 적으면 거꾸로 움직입니다. BPM은 20~500 BPM을 0~1로 봅니다.
- **모양** — 0~1 값을 sin, tri, saw, sq 파형으로 바꾸고, **반전**은 1−값입니다. **프리런**은 입력 없이 정한 주기로 혼자 흐릅니다.
- **시간 형식** — 시간 값(Time, Length, Remain, SMPTE, Clock)의 자리(hh, mm, ss, ff)를 고릅니다. 아래 "시간 형식" 참고.
- **줄바꿈** — 글자 값을 여러 줄로 잇습니다(예: 제목 / 아티스트).

계산은 출력 엔진에서 하므로 다른 페이지를 보고 있어도 계속 나갑니다.

### 값 이름과 보내는 값

범위를 적지 않았을 때 보내는 값입니다.

| 묶음 | 이름 | 값 |
| --- | --- | --- |
| 믹서 채널별 (채널 1~6) | Fader, VU, Hi, Mid, LoMid, Low, Color | 0~1 |
| | OnAir | 온에어면 1, 아니면 0 |
| 믹서 전체 | Xf, MVU, MVUL, MVUR, BeatFX | 0~1 |
| | BeatFXOn | 비트 FX가 ON이면 1 |
| | BeatFXName, BeatFXCh, ColorFXName | 고른 비트 FX 이름, 비트 FX를 건 채널, 컬러 FX 이름 (string) |
| 덱별과 마스터 덱 | BPM | BPM 그대로 (string이면 `128.0`처럼 소수 첫째 자리). BPMCoarse는 정수 부분, BPMFine은 소수 부분 |
| | Pos | 곡 진행 0~1 (string이면 `42%`) |
| | Beat, Downbeat | 비트마다 잠깐 1, 마디 첫 비트에만 잠깐 1 |
| | Phase | 비트 안의 위치 0~1 |
| | BarBeat | 마디 안에서 몇 번째 비트인지 1~4 |
| | BarPhase | 마디 안의 위치 0~1 (네 비트에 한 바퀴) |
| | Phrase | rekordbox 프레이즈 이름 (string, 예: `CHORUS`) |
| | PhraseKind | 프레이즈 번호: Intro 1, Verse 2, Bridge 3, Chorus 4, Up 5, Down 6, Outro 7 (프레이즈가 없으면 0) |
| | PhrasePos, PhraseBeats | 프레이즈 안의 위치 0~1, 다음 프레이즈까지 남은 비트 수 |
| | Loop, Sync | 루프 중이면 1, 싱크가 켜져 있으면 1 |
| | Title, Artist, Key | 곡 제목, 아티스트, 키 (string) |
| | Time, Length, Remain | 현재 시간, 전체 시간, 남은 시간 (string, `MM:SS`, 남은 시간은 `-MM:SS`) |
| 덱별만 | CDJPlay, CDJCue | 재생 중이면 1, CUE를 누르는 동안 1 |
| | Master | 그 덱이 CDJ 마스터면 1 |
| 마스터 덱만 | Deck | 마스터 덱의 플레이어 번호 1~6 |
| SMPTE, 시계 | SMPTEA, SMPTEB, SMPTEM | SMPTE OUT의 A, B, MASTER 레이어 타임코드, 도크에 보이는 값 (string, `HH:MM:SS:FF`, 29.97 드롭 프레임은 `HH:MM:SS;FF`, 오프셋 포함) |
| | Clock | 컴퓨터 시각 (string, `HH:MM:SS`) |

- 마스터 덱은 헤더 MASTER BPM과 같은 덱입니다. CDJ 마스터가 없으면 재생 중인 덱을 쓰며 온에어인 덱을 먼저 씁니다.
- Resolume 템포 주소(`/composition/tempocontroller/tempo`)로 보내는 BPM은 0~1(20~500 BPM)로 보냅니다. Resolume이 이 주소에서 0~1 값을 받기 때문입니다.
- 믹서가 없으면 믹서 값은 보내지 않습니다. 0을 보내면 페이더에 묶어 둔 레이어가 꺼지기 때문입니다. BPM이 없는 덱의 BPM도 보내지 않습니다.
- 켜고 끄는 값(OnAir, BeatFXOn, Loop, Sync, CDJPlay, CDJCue, Master)과 Deck은 string으로도 보낼 수 있습니다(`ON`, `OFF`, `2`).

### 시간 형식

시간 값에 시간 형식 노드를 붙이면 고른 자리만 보냅니다.

| 글자 | 자리 |
| --- | --- |
| `hh`, `h` | 시 |
| `mm`, `m` | 분 |
| `ss`, `s` | 초 |
| `ff`, `f` | 프레임 (SMPTE만) |

두 글자로 쓰면 앞에 0을 붙여 두 자리로 보내고 한 글자로 쓰면 그대로 보냅니다. 여러 자리를 이어 쓰면 `:`로 이어 보냅니다(예: `mmss` → `05:08`, `hmmss` → `0:05:08`). 곡 시간은 `h`를 쓰지 않으면 분이 60을 넘어도 그대로 셉니다. Remain에 형식을 붙이면 `-` 없이 보냅니다. 29.97 드롭 프레임 타임코드는 프레임 앞을 `;`로 보냅니다.

## 14. SHORTCUT과 MAP

키보드, MIDI, OSC, DMX(Art-Net)로 ORVIK의 버튼을 누르고 값을 바꿉니다. 받는 쪽만 설정하면 되고, 지정한 버튼의 켜짐, 꺼짐은 MIDI OUT으로 돌려보낼 수 있습니다.

### SHORTCUT 페이지

| 구역 | 내용 |
| --- | --- |
| 키보드 | ORVIK 창이 앞에 있을 때만 듣는 키 조합입니다. |
| MIDI 입력 | 듣는 MIDI 장치(모든 장치 또는 하나)입니다. OUT을 켜면 지정한 버튼의 상태를 그 장치로 돌려보냅니다(컨트롤러 LED). |
| OSC 입력 | OSC 수신 포트, 받는 곳(모든 인터페이스 또는 이 컴퓨터만), 보낼 수 있는 IP 목록입니다. 목록을 비우면 같은 망의 누구나 조작할 수 있으니 공연장에서는 IP를 적어 두세요. |
| DMX 입력 (Art-Net) | Art-Net 유니버스의 채널로 조작합니다. 같은 컴퓨터의 Resolume과 함께 받을 수 있습니다. |
| 버튼에서 지정 | **MAP 켜기**로 지정 모드에 들어갑니다. |

지정 목록에는 동작마다 키, MIDI(채널, 노트 또는 CC), OSC 주소, DMX 채널이 나옵니다. 지울 수도 있습니다.

### MAP

사이드바의 MAP(또는 SHORTCUT 페이지의 MAP 켜기)을 누르면 지정 모드가 됩니다. 화면의 버튼을 누르면 그 버튼이 고정되고, 그다음 누르는 키, MIDI 입력, OSC 메시지, DMX 채널이 그 버튼에 지정됩니다. Esc로 지정 모드를 나갑니다. 지정할 수 있는 버튼은 지정 모드에서 테두리가 표시됩니다.
