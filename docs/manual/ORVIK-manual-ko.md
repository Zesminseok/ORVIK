## 1. 시작하기 전에

### ORVIK은

ORVIK은 CDJ와 DJM의 재생 정보를 받아 조명이나 영상 프로그램으로 보내는 앱입니다. TCNet, SMPTE 타임코드(LTC, MTC, Art-Net), OSC, DMX(Art-Net, sACN), MIDI, MIDI Clock으로 내보냅니다. 셋리스트의 큐를 큐 콜 창에 띄워 스태프에게 보여 주고 음성으로 알려 줄 수도 있습니다. 장비에는 정보를 요청하기만 하며 제어하지 않습니다.

**안전.** ORVIK은 안전 장치가 아닙니다. 네트워크, 컴퓨터, 덱에 문제가 생기면 출력(타임코드, OSC, DMX, MIDI, 큐 동작)이 늦거나 멈추거나 반복될 수 있습니다. 화염, 파이로, CO2, 레이저, 움직이는 기계처럼 사람이 다치거나 재산이 손상될 수 있는 장치를 ORVIK만으로 작동시키거나 유지하지 마세요. 이런 효과에는 별도의 안전 장치가 필요합니다. 훈련된 운용자가 잡고 있는 허가(데드맨) 스위치, 비상 정지, 장비 제조사와 현지 규정이 정한 제한을 따르세요. 공연 전에 실제 수신 장비로 모든 큐를 확인하세요.

### 사용 환경

| 항목 | 내용 |
| --- | --- |
| 운영체제 | macOS 13.3 이상(Apple Silicon), Windows 10, 11(x64) |
| 확인한 장비 | CDJ-3000X, CDJ-3000, CDJ-2000NXS2, DJM-V10, DJM-900NXS2 |

장비, 펌웨어, 연결 구성에 따라 받을 수 있는 정보가 다릅니다.

### 설치와 실행

- **macOS** — DMG를 열어 ORVIK을 응용 프로그램 폴더로 옮깁니다.
- **Windows** — 다운로드한 `.exe`를 바로 실행합니다. 설치 과정이 없습니다. 코드 서명이 없어 처음 실행할 때 SmartScreen 경고가 뜨면 "추가 정보"를 누른 뒤 "실행"을 선택합니다.

실행할 때와 종료할 때 짧은 스플래시 화면이 표시됩니다. 종료할 때는 TCNet과 PRO DJ LINK 연결을 정리한 뒤 닫힙니다.

### 첫 연결

1. 이 컴퓨터를 플레이어, 믹서와 같은 네트워크(같은 스위치나 공유기)에 연결합니다. Arena로 보내는 TCNet은 같은 네트워크로 보내도 되고 두 번째 어댑터로 보내도 됩니다.
2. ORVIK을 실행합니다. PRO DJ LINK와 TCNET은 자동으로 켜집니다([설정](#15-설정)의 **PRO DJ LINK 자동 시작**, **TCNet 자동 시작**). 켜지지 않으면 헤더에서 켭니다.
3. 플레이어가 DECKS와 NETWORK에 나타납니다. **자동 감지**로 두면 CDJ가 보이는 어댑터를 사용합니다. 어댑터를 하나로 고정하려면 설정의 **PRO DJ LINK 인터페이스**에서 선택합니다.
4. 기기가 나타나지 않으면 NETWORK에 연결 구성의 문제와 해결 방법이 표시됩니다. [12.1](#121-연결-구성-경고)

macOS에서는 시스템 설정 > 개인정보 보호 및 보안 > 로컬 네트워크에서 ORVIK을 허용합니다. Windows에서는 방화벽이 물을 때 ORVIK을 허용합니다. 공유기 없이 연결한 어댑터는 공용 네트워크로 잡히므로 공용 네트워크도 허용합니다.

## 2. 화면 구성

![화면 구성](images/01-overview.png)

1. **헤더** — 마스터 BPM, PRO DJ LINK, TCNET 스위치, CUE CALL 버튼, 볼륨, 창 버튼이 있습니다. [3장](#3-헤더)
2. **사이드바** — 페이지를 선택합니다. [4장](#4-사이드바)
3. **페이지** — 사이드바에서 선택한 화면이 표시됩니다. 스크린샷은 DECKS 페이지입니다.
4. **SMPTE OUT 도크** — 타임코드 출력을 확인하고 조절합니다. 클릭하면 펼쳐집니다. [7장](#7-smpte-out)
5. **상태 바** — 송출 상태와 앱 상태를 표시합니다. [5장](#5-상태-바)

CUE CALL 창을 메인 창에 붙이면 페이지 오른쪽에 큐 콜 패널이 나타납니다. [11장](#11-cue-call)

## 3. 헤더

![헤더](images/02-header.png)

1. **MASTER BPM** — CDJ 마스터의 BPM입니다. CDJ 마스터에 BPM이 없으면 재생 중인 덱의 BPM이 표시되며, 온에어인 덱을 우선합니다. 왼쪽 영역은 CDJ 마스터의 플레이어 번호입니다.
2. **PRO DJ LINK** — CDJ와 DJM 연결을 켜고 끕니다.
3. **TCNET** — 조명이나 영상 프로그램으로 보내는 TCNet 송출을 켜고 끕니다. 설정의 TCNet 모드가 Client이거나 STANDBY 상태이면 켜져 있어도 송출하지 않습니다.
4. **CUE CALL** — 큐 콜을 메인 창 오른쪽에 붙여서 엽니다. 한 번 더 누르면 모든 큐 콜이 닫히고, Alt+클릭(Mac은 Option+클릭)은 따로 창으로 엽니다. 큐 콜이 열려 있는 동안 버튼이 채워진 상태로 표시됩니다. [11장](#11-cue-call)
5. **새로고침** — 화면을 다시 불러옵니다(Cmd/Ctrl+R). 가상 덱 재생은 멈춥니다.
6. **M.VOL** — 앱이 출력하는 가상 덱 소리의 볼륨입니다. CDJ와 믹서 소리에는 영향이 없습니다.
7. **창 버튼** — Windows에서 창을 최소화, 최대화하고 ORVIK을 종료합니다. macOS에서는 창 왼쪽 위의 기본 버튼을 사용하고, 윈도우 메뉴에 최소화(⌘M)와 닫기(⌘W)가 있습니다. 저장하지 않은 히스토리나 셋리스트가 있으면 종료할 때 저장할지 묻습니다.

### 스위치 상태

PRO DJ LINK와 TCNET 스위치는 켜지면 왼쪽 영역이 상태 색으로 채워집니다. 정상이면 초록이고, 켜는 동안에는 점이 깜빡입니다. 확인이 필요하면 스위치 안에 아래 표시가 나타납니다.

| 표시 | 뜻 |
| --- | --- |
| NO H/W | PRO DJ LINK는 켜져 있지만 CDJ, DJM이 감지되지 않습니다. |
| LOST | 하드웨어 덱은 있지만 어느 CDJ에서도 1.5초 넘게 상태가 수신되지 않습니다. |
| STANDBY | 같은 네트워크에 먼저 켜진 TCNet 서버가 있어 송출을 멈추고 기다리는 중입니다. |

네트워크 구성 때문에 플레이어와 믹서의 신호가 ORVIK에 닿지 않으면 PRO DJ LINK 스위치의 툴팁에 원인이 표시됩니다. [12.1](#121-연결-구성-경고)

새 버전이 나오면 헤더에 UPDATE 표시가 나타납니다. 클릭하면 다운로드 페이지를 엽니다.

## 5. 상태 바

![상태 바](images/05-status-bar.png)

1. **TCNET** — 헤더의 TCNET 스위치가 켜져 있는지 나타냅니다. STANDBY일 때는 ON이어도 송출하지 않습니다.
2. **ARENA** — 최근 10초 안에 확인된 TCNet 노드 수입니다.
3. **DECKS** — 하드웨어 덱과, 곡이 올라간 가상 덱을 더한 수입니다.
4. **UP** — 엔진이 켜진 뒤 경과한 시간입니다.
5. **CPU** — ORVIK의 CPU 사용률입니다.
6. **GPU** — ORVIK이 그래픽 카드를 사용하는 시간의 비율입니다. 시스템이 이 값을 알려 줄 때만 표시됩니다.
7. **MEM** — ORVIK이 사용하는 메모리 양입니다.
8. **덱 점** — 덱마다 점 하나입니다. 하드웨어 덱은 하드웨어 색으로, 가상 덱은 재생, 큐, 곡 있음, 빈 덱에 따라 다른 색으로 표시됩니다.

문제가 생기면 상태 바에 LINK, OUT, MIX 표시가 나타납니다. LINK는 플레이어 번호가 겹치거나 네트워크 구성을 확인해야 할 때(예: PDJL 기기 수신 없음, PDJL 다른 서브넷), OUT은 TCNet 송출이 멈췄거나 미러 상태일 때, MIX는 믹서 데이터가 끊겼을 때 켜집니다. 클릭하면 관련 페이지로 이동하며, 문제가 없으면 나타나지 않습니다.

## 6. DECKS

### 6.1 덱 모드와 연결 기기

![덱 모드와 연결 기기](images/03-deck-top.png)

1. **덱 모드** — HARDWARE는 PRO DJ LINK 네트워크의 CDJ를 따라갑니다(기본). VIRTUAL은 컴퓨터의 오디오 파일을 재생하는 가상 덱을 사용합니다. 모드를 바꾸면 현재 덱이 사라지며, 가상 덱이 있을 때 HARDWARE로 바꾸면 먼저 확인을 받습니다. [6.4](#64-가상-덱)
2. **CDJ** — 연결된 플레이어의 번호와 기종입니다. 마우스를 올리면 IP 주소가 표시되고, 우클릭하면 덱 색을 선택합니다.
3. **DJM** — 연결된 믹서의 기종입니다. 믹서 조작 값이 1.5초 넘게 수신되지 않으면 NO DATA가 표시됩니다.

### 6.2 덱 카드

![덱 카드](images/04-deck-card.png)

스크린샷은 FLOW 레이아웃의 덱 카드입니다. 레이아웃에 따라 일부 요소가 빠지거나 위치가 바뀝니다.

1. **플레이어 번호** — 우클릭하면 덱 색을 선택합니다.
2. **곡 제목, 아티스트**
3. **키** — 곡의 키입니다. 8A 같은 카멜롯 표기로 변환해 표시하며, 변환할 수 없는 키는 원래 값 그대로 표시합니다.
4. **ON AIR** — 믹서에서 이 덱의 채널이 온에어일 때 켜집니다.
5. **MASTER** — 이 덱이 CDJ 마스터일 때 켜집니다.
6. **SYNC** — Beat Sync가 켜져 있을 때 켜집니다.
7. **채널 페이더, 레벨 인디케이터** — DJM의 채널 페이더 위치와 채널 레벨입니다.
8. **재생 상태** — PLAY, PAUSE, CUE, LOOP 등입니다.
9. **기종, 미디어** — CDJ 기종과, 곡이 저장된 미디어(플레이어 번호와 USB, SD)입니다. 미디어 칩의 색은 rekordbox에서 지정한 미디어 색이고, 색을 지정하지 않은 미디어는 회색입니다. 색 정보가 없으면 칩 대신 텍스트로 표시됩니다.
10. **크게 고정** — FLOW 레이아웃에서 이 덱을 크게 고정합니다. 다시 누르거나 곡이 바뀌면 해제됩니다.
11. **디테일 웨이브폼** — 재생 위치 주변의 파형입니다. 빨간 선이 재생 위치입니다.
12. **마디 카운터** — 다음 메모리 큐까지 남은 마디입니다. 8마디 이하가 되면 빨갛게 바뀌고, 앞에 메모리 큐가 없으면 경과한 마디가 표시됩니다. 클릭하면 초 단위로 바뀝니다.
13. **줌** — −로 파형을 넓게(누를 때마다 2배), +로 좁게(최소 0.5초) 표시합니다. RST는 기본 8초로 되돌립니다.
14. **오버뷰 웨이브폼** — 곡 전체의 파형입니다. 하드웨어 덱에서는 누르고 있는 동안 그 위치의 디테일 웨이브폼을 미리 보여 주고, 손을 떼면 돌아옵니다. 미리 보는 동안 마디 카운터에는 재생 위치와의 차이가 초나 분:초로 표시됩니다.
15. **타임코드** — 현재 재생 위치의 타임코드입니다.
16. **시간** — 클릭하면 경과 시간과 남은 시간이 전환됩니다. 오른쪽은 곡 길이입니다.
17. **비트 위치** — 마디 안에서 지금 몇 번째 비트인지 표시합니다.
18. **BPM** — 왼쪽 위는 곡의 원래 BPM, 그 아래는 템포 변경(%), 오른쪽 큰 숫자는 현재 BPM입니다.
19. **SMPTE MASTER** — 이 덱을 레이어 A나 B에 배정하고, 그 레이어를 MASTER의 소스로 지정합니다. 다시 누르면 MASTER 소스만 해제되고 A, B 배정은 남습니다. LTC, MTC, Art-Net 출력은 SMPTE OUT에서 따로 켭니다.
20. **SMPTE A, B** — 이 덱을 SMPTE 레이어 A 또는 B의 소스로 지정합니다.

웨이브폼 색을 3밴드로 선택했는데 곡에 3밴드 데이터가 없으면 덱에 ! 표시가 나타나고 RGB로 표시됩니다. 웨이브폼은 그래픽 카드(GPU)로 그립니다.

### 6.4 가상 덱

![가상 덱](images/07-virtual-deck.png)

덱 모드를 VIRTUAL로 바꾸면 컴퓨터의 오디오 파일을 재생하는 가상 덱을 사용합니다. 가상 덱은 레이아웃 테마와 상관없이 늘 FLOW 카드로 표시되며, 재생 버튼(⑧)은 타임코드와 BPM 사이에 있습니다. 스크린샷은 곡이 올라간 덱 하나와 빈 덱 하나입니다.

1. **덱 번호**
2. **VIRTUAL** — 이 컴퓨터의 파일을 재생하는 가상 덱이라는 표시입니다.
3. **×** — 이 가상 덱을 삭제합니다.
4. **채널 페이더** — 드래그해 조절합니다.
5. **꺼내기** — 덱에서 곡을 뺍니다.
6. **디테일 웨이브폼** — 드래그하면 재생 위치를 앞뒤로 옮깁니다.
7. **오버뷰 웨이브폼** — 클릭하거나 드래그해 재생 위치를 옮깁니다.
8. **|◀, CUE, ▶** — CUE는 멈춘 상태에서 누르면 그 위치를 큐 지점으로 정하고 누르는 동안 들려 줍니다. 재생 중에 누르면 큐 지점으로 돌아갑니다. ▶는 재생, 일시정지, |◀는 멈추고 곡 처음으로 돌아갑니다.
9. **열기** — 눌러서 오디오 파일을 선택하거나 파일을 여기로 끌어다 놓습니다.
10. **가상 덱 추가** — 가상 덱을 하나 추가합니다. 최대 6개입니다.

열 수 있는 파일은 MP3, WAV, AIFF, FLAC, AAC, M4A(AAC, ALAC), OGG, MP4(오디오)입니다. CDJ가 여는 형식은 모두 열립니다.

가상 덱 소리는 [설정](#15-설정)의 **오디오 출력**에서 선택한 장치로 출력되며 볼륨은 헤더의 M.VOL로 조절합니다.

## 7. SMPTE OUT

![SMPTE OUT](images/06-smpte-dock.png)

타임코드 출력 레이어는 A, B, MASTER 세 개입니다. 레이어 A, B는 선택한 덱의 재생 위치를, MASTER는 A, B 레이어나 컴퓨터 시각, FREEWHEEL 중 하나를 타임코드로 출력합니다. 스크린샷은 레이어 A와 MASTER이며 레이어 B는 A와 같습니다.

1. **SMPTE OUT** — 눌러서 도크를 펼치거나 접습니다. 접혀 있을 때는 레이어마다 연결 상태를 보여 주고, 이어서 켜진 출력을 보여 줍니다. A ← 1은 레이어 A가 덱 1을 따라간다는 뜻이고, MASTER ← A는 MASTER가 레이어 A를 내보낸다는 뜻입니다. 그 뒤에 MASTER 타임코드가 표시됩니다.
2. **따로 열기** — SMPTE OUT을 별도 창으로 엽니다. 창을 닫으면 도크로 돌아옵니다.
3. **레이어 A** — 선택한 덱의 재생 위치를 타임코드로 출력하는 레이어입니다. 레이어 B도 같습니다.
4. **LTC, MTC, ART** — 이 레이어의 LTC(오디오 타임코드), MTC(MIDI 타임코드), ART(Art-Net 타임코드) 출력을 켜고 끕니다. LTC는 레이어마다 켤 수 있고, MTC와 ART는 한 번에 한 레이어만 켤 수 있습니다(하나를 켜면 다른 레이어에서는 꺼집니다). LTC 장치와 MTC 포트는 [설정](#15-설정)의 **SMPTE Timecode 출력**에서, Art-Net 네트워크는 [OUTPUT](#13-output) 페이지 위쪽에서 선택합니다. Art-Net 타임코드는 SMPTE의 **Frame Rate**를 사용합니다.
5. **소스 덱** — 이 레이어가 따라갈 덱을 선택합니다. 덱 카드의 A, B 버튼과 같습니다.
6. **타임코드** — 소스 위치에 오프셋을 더한 타임코드입니다. 실제 송출에는 설정의 **레이턴시 보정**이 더해집니다.
7. **− / +** — 각 자리의 값을 1씩 바꿉니다. Ctrl(맥은 Cmd)을 누른 채 클릭하면 10씩 바꿉니다. MASTER의 STEP이 TIME이면 FREEWHEEL 시간을, 그 밖에는 오프셋을 바꿉니다.
8. **SET** — 셋리스트의 오프셋이 이 레이어에 적용돼 있다는 표시입니다. 마우스를 올리면 곡 이름이 보입니다. 목록에 없는 곡이라 UNLISTED 오프셋이 적용되면 SET —로 표시됩니다.
9. **OFFSET ON** — 오프셋을 송출에 적용하거나 해제합니다. 값은 그대로 둡니다.
10. **되돌리기** — 오프셋을 0으로 되돌립니다.
11. **MASTER** — MASTER 레이어입니다.
12. **FREEWHEEL 버튼** — ▶는 FREEWHEEL 타임코드를 진행시키고, ❚❚는 값을 유지한 채 멈춥니다. |◀는 00:00:00:00으로 되돌립니다. READY(◉)를 누르면 FREEWHEEL이 현재 값에서 멈추고 기다리다가, 덱이 새로 재생을 시작할 때 출발합니다. 믹서가 있으면 그 순간 온에어인 덱만 대상으로 하며, 이미 재생 중이던 덱과 CUE로 미리 듣는 것은 제외합니다.
13. **소스** — A, B는 그 레이어의 타임코드에 MASTER 오프셋을 더해 출력합니다. CLOCK은 컴퓨터 시각을 사용하고, FREEWHEEL은 직전 MASTER 값에서 이어서 스스로 진행합니다.
14. **STEP** — MASTER 소스가 FREEWHEEL일 때, − / + 버튼이 오프셋(OFS)을 바꿀지 FREEWHEEL 시간(TIME)을 바꿀지 선택합니다.

설정의 **정지 중 LTC 유지**가 켜져 있으면(기본) 덱이 멈춰 있어도 LTC는 멈춘 위치의 타임코드를 계속 출력합니다. 수신 측이 멈춤을 알 수 있도록 같은 프레임이 반복됩니다. 끄면 덱이 멈춰 있는 동안 LTC가 나가지 않습니다.

## 9. HISTORY

![HISTORY](images/14-history.png)

온에어로 나간 곡을 실제 시각과 덱 번호로 기록합니다. 믹서가 있으면 재생 중이면서 온에어인 시간을, 없으면 재생 중인 시간을 측정해 10초 이상이면 기록합니다. 재생이나 온에어가 3초 넘게 끊겼다가 다시 시작되면 같은 곡이라도 새 행으로 기록하고 3초 안에 돌아오면 한 행으로 이어집니다. 가상 덱은 곡을 올리면 바로 기록하고 재생한 시간을 측정합니다. 지금 나가는 곡은 END 열에 LIVE가 표시됩니다.

기록은 ORVIK을 실행할 때마다 새로 시작합니다. 기록은 자동으로 저장되며, ORVIK이 비정상적으로 종료됐다면 다음에 실행할 때 이어서 기록할지 묻습니다.

1. **시작 시각** — 이번 기록을 시작한 날짜와 시각입니다.
2. **곡 수** — 기록된 곡 수입니다.
3. **IMPORT** — 히스토리 파일(ORVIK CSV, ShowKontrol 히스토리 CSV, TXT)을 불러와 현재 기록에 합칩니다. 파일의 기록은 수정하거나 빼지 않고 그대로 가져옵니다.
4. **EXPORT** — 형식을 선택해 저장합니다. ORVIK CSV(ORVIK으로 다시 불러올 수 있음), ShowKontrol 히스토리, ShowKontrol 셋리스트, 트랙리스트 TXT 중에서 선택합니다.
5. **⋯** — **자동 저장 기록…**은 이전 기록 사본을 되돌리고([자동 저장](#자동-저장-기록)), **기록 전체 지우기…**는 확인을 받은 뒤 기록을 모두 지웁니다.
6. **EVENT** — 행사 이름입니다. 내보내는 파일 이름(ORVIK CSV, 셋리스트, 트랙리스트)과 트랙리스트 TXT 본문에 포함됩니다.
7. **DJ** — DJ 이름입니다. 트랙리스트 TXT 본문에 포함됩니다.
8. **검색** — 제목이나 아티스트로 찾습니다.
9. **열 머리글** — 경계를 드래그해 열 너비를 바꾸고 더블클릭하면 원래대로 돌아갑니다. 열은 다음과 같습니다.
   - **DECK** — 곡이 나간 플레이어 번호와 기종입니다.
   - **START, END** — 온에어가 시작된 시각과 끝난 시각입니다.
   - **IN, OUT** — 온에어가 시작될 때와 끝날 때의 재생 위치입니다.
   - **ON AIR** — 온에어로 나간 시간입니다.
10. **합계** — 재생 곡 수, 총 ON AIR 시간, 평균 BPM, 덱별 곡 수입니다.

행 오른쪽 끝의 버튼은 곡을 셋리스트에 추가합니다. 셋리스트에 들어간 곡은 버튼이 주황색 체크로 바뀌고, 다시 누르면 한 번 더 추가됩니다. 행에 마우스를 올리면 옆에 행을 지우는 ×가 나타납니다. 두 버튼 모두 왼쪽 클릭으로 동작합니다. 지금 나가는 곡을 지우면 그 곡이 재생되는 동안은 다시 기록하지 않습니다. 터치스크린에서는 손가락으로 목록을 끌어 스크롤합니다.

### 자동 저장 기록

ORVIK은 히스토리, 셋리스트, 큐, OUTPUT 노드의 사본을 남깁니다. 바뀐 뒤 5분이 지나면 하나, 지우거나 가져오거나 파일을 불러오기 전에 하나, ORVIK을 종료할 때 하나를 남깁니다. 각 페이지의 **⋯ > 자동 저장 기록…**에 사본이 최신순으로 나오며 시각, 남긴 이유, 담긴 내용(곡, 큐, 행, 노드 수)이 함께 표시됩니다. **복원**을 누르면 선택한 사본으로 되돌립니다. 되돌리기 전에 지금 상태도 사본으로 남기므로 다시 돌아올 수 있습니다. **폴더 열기**는 파일 관리자에서 사본을 보여 줍니다.

## 10. SET LIST

![SET LIST](images/15-setlist.png)

곡마다 타임코드 오프셋과 큐를 정해 두는 목록입니다. APPLY TO SMPTE를 켜 두면, 목록에 있는 곡이 덱에 올라올 때 그 덱이 연결된 SMPTE 레이어(A, B)에 곡의 오프셋이 적용됩니다. 셋리스트도 히스토리처럼 ORVIK을 실행할 때마다 비워지며, 자동으로 저장되고 [자동 저장 사본](#자동-저장-기록)을 남깁니다.

1. **곡 수** — 목록의 곡 수입니다.
2. **APPLY TO SMPTE** — 켜면 목록에 있는 곡이 덱에 올라올 때 그 곡의 오프셋을 그 덱에 연결된 레이어에 적용합니다. 재생 중인 덱도 바로 바뀝니다. 끄면 레이어 오프셋을 그대로 둡니다.
3. **되돌리기, 다시 실행** — 목록의 변경을 되돌리고 다시 실행합니다. 되돌리기는 Ctrl+Z(맥은 Cmd+Z), 다시 실행은 Ctrl+Shift+Z 또는 Ctrl+Y(맥은 Cmd+Shift+Z)입니다.
4. **IMPORT** — 셋리스트를 불러옵니다. ORVIK 파일(.json), ShowKontrol 셋리스트(.set)나 히스토리(.csv), rekordbox에서 내보낸 텍스트 플레이리스트(.txt), 음원 파일을 열 수 있습니다. 목록이 있으면 바꿀지(**바꾸기**) 뒤에 추가할지(**추가**) 묻고, 텍스트 파일의 열 이름을 인식하지 못하면 사용할 열을 선택하게 합니다. ORVIK 파일에는 큐도 함께 포함돼 있습니다.
5. **EXPORT** — ORVIK 셋리스트(목록 밖 오프셋과 큐 포함)나 ShowKontrol 셋리스트(.set: 제목, 아티스트, 오프셋, 길이)로 저장합니다.
6. **⋯** — **재생한 곡 표시 지우기**가 있고, **자동 저장 기록…**은 이전 목록 사본을 되돌리며, **목록 전체 지우기…**는 확인을 받은 뒤 모든 곡을 지웁니다(되돌리기로 복구할 수 있습니다). 곡의 큐도 함께 지워집니다.
7. **곡 추가** — **직접 추가**는 제목, 아티스트, 오프셋 순서로 입력해 곡을 추가하며, Enter로 다음 칸으로 넘어갑니다. **덱에서** 옆의 덱 번호를 누르면 그 덱에 올라온 곡을 추가합니다.
8. **목록 밖** — 목록에 없는 곡에 적용할 오프셋입니다. 옆 버튼은 00:00:00:00으로 되돌립니다. 큐가 없는 구간(예: 23:00:00:00)으로 정합니다.
9. **자동 채우기** — 시작 시각을 입력하고 **FILL**을 누르면 목록 순서대로 한 시간 간격으로 모든 곡에 오프셋을 채웁니다. 채운 오프셋은 하나씩 고칠 수 있습니다.
10. **검색** — 제목이나 아티스트로 찾습니다.
11. **OFFSET** — 이 곡의 오프셋입니다. 클릭해 편집하고(HH:MM:SS:FF, 24시간 미만), 옆 버튼은 00:00:00:00으로 되돌립니다.
12. **큐** — 곡의 큐 개수입니다. 큐가 없으면 **큐 편집**으로 표시됩니다. 이것을 누르거나 곡을 더블클릭하면 목록 아래에 큐 편집기가 열립니다. [10.1](#101-큐-편집)
13. **STATUS** — 곡이 덱에 올라와 있으면 ▶와 덱 번호, 이어서 오프셋이 적용된 레이어(A, B)가 표시됩니다. 그 덱이 어느 레이어에도 연결돼 있지 않으면 가로줄이 표시됩니다. APPLY TO SMPTE가 켜진 동안 곡이 재생되고 온에어로 나가면 체크가 표시되고 행이 흐려집니다. 믹서가 없으면 재생 여부만 확인합니다. 같은 곡이 목록에 여러 번 있으면 아직 체크가 없는 행의 오프셋을 사용합니다. 한 번만 있으면 다시 틀어도 그 행의 오프셋을 사용합니다.
14. **덱에 있는 곡** — 덱에 올라와 있는 곡의 행은 왼쪽에 막대가 표시됩니다.

제목, 아티스트, 오프셋은 클릭하면 편집할 수 있습니다. 행의 손잡이를 끌면 순서가 바뀌고, 행 오른쪽 끝의 휴지통 버튼은 곡을 목록에서 지웁니다. 열 머리글의 경계를 드래그하면 열 너비가 바뀌고 더블클릭하면 원래대로 돌아갑니다. 터치스크린에서는 손가락으로 목록을 끌어 스크롤합니다.

- **파형** — 곡 전체 파형과 확대 파형입니다. 비트 그리드, 마디 번호, 프레이즈 띠, 큐 표시가 그려집니다. 파형은 음원 파일, HISTORY의 기록, CDJ에서 받은 파형 중 있는 것을 사용합니다. CDJ 파형을 사용하려면 트랙 라이브러리를 켜 둡니다(편집기의 안내에서 켤 수 있습니다). 파형이 없어도 시간만으로 큐를 추가할 수 있습니다.
- **위치 옮기기** — 파형을 클릭하면 편집 위치가 옮겨집니다. **스냅**(끔, 박, 마디, 프레임)으로 위치를 그리드에 맞춥니다. **줌**으로 확대 파형의 범위를 바꿉니다.
- **+ 큐 (C)** — 편집 위치에 큐를 만듭니다. 음원이 있으면 그 위치를 미리 들려 줍니다.
- **핫큐 가져오기** — rekordbox 핫큐와 메모리 포인트를 큐 위치로 가져옵니다.
- **큐 목록** — 시간, 마디.박, 이름, 그룹, 동작 요약입니다.
- **큐 설정** — 선택한 큐의 이름, 시간, 마디.박, 그룹, 미리 알림(기본값 따름 또는 박 수), 음성(그룹 따름, 켜기, 끄기), 말할 내용(비우면 큐 이름을 말함), 동작 목록입니다.
- **동작 목록** — 위에서부터 차례로 실행합니다. OSC(보내는 곳, 주소, 형식 i/f/s, 값), Art-Net DMX(유니버스, 채널=값 여러 개), MIDI(장치, 채널, Note on/off, CC, Program), 대기(ms 또는 박, 마디)를 추가할 수 있습니다. 보내는 곳 목록은 OUTPUT 페이지와 같습니다.
- **그룹** — 큐의 담당 그룹입니다. 기본 그룹은 조명, 영상, 특효, 레이저이고, 그룹 메뉴의 **그룹 편집…**에서 이름과 색을 바꾸거나 추가합니다. 그룹은 큐 콜 창의 표시와 음성 출력에 사용됩니다.
- **큐 출력** — 편집기 위의 스위치로 큐 동작 송출을 켜고 끕니다.

큐는 마스터 덱에서 재생 중인 곡에만 반응합니다. 마스터 덱의 곡이 셋리스트에 없으면 큐를 내보내지 않습니다. 큐는 곡의 비트 그리드와 재생 위치로 박을 계산해 그 박에 내보냅니다. 큐는 셋리스트 항목에 연결돼 있어, 같은 곡이라도 셋리스트마다 큐가 따로 관리됩니다.

사람이 다칠 수 있는 효과(화염, CO2, 파이로, 레이저)로 가는 큐 동작은 반드시 그 효과의 안전 장치를 거치게 하세요. 1장의 **안전**을 참고하세요.

## 11. CUE CALL

큐 콜은 한 덱에 올라온 곡의 셋리스트 큐를 담당 그룹별로 보여 주고, 다음 큐까지 남은 시간을 카운트다운합니다. 헤더의 CUE CALL을 누르면 메인 창 오른쪽에 큐 콜이 붙은 채로 열립니다. CUE CALL을 다시 누르면 모든 큐 콜이 닫힙니다. Alt+클릭(맥은 Option+클릭)하면 큐 콜을 별도 창으로 하나 더 엽니다. 예를 들어 조명 담당용과 특효 담당용을 따로 띄울 수 있습니다. 위치, 크기, 표시 설정은 창마다 따로 저장되며, ORVIK을 종료할 때 열려 있던 큐 콜은 다음 실행 때 다시 열립니다.

### 열기와 붙이기

- **붙이기** — 큐 콜 헤더에서 스피커 왼쪽 버튼을 누르면 메인 창 오른쪽에 붙이거나 다시 별도 창으로 엽니다. 헤더를 더블클릭해도 같습니다.
- **끌기** — 헤더(또는 창 제목줄)를 끌어 큐 콜 창을 옮깁니다. 메인 창 오른쪽 가장자리에 놓으면 그 자리에 붙습니다. 오른쪽에는 패널을 위아래로 두 개까지 붙일 수 있고, 경계선을 끌면 너비가 바뀝니다.
- **윈도우 메뉴** — macOS에서는 큐 콜 창마다 윈도우 메뉴와 Dock 메뉴에 표시됩니다. 윈도우 > 닫기(⌘W)는 앞에 있는 큐 콜 창을 닫습니다.

창 제목에는 보여 주는 그룹이 "큐 콜 (전체)"나 그룹 이름으로 표시됩니다.

### 따라가는 덱

설정 팝업의 **따라갈 덱**은 모든 큐 콜 창과 음성 안내가 따라갈 덱을 정합니다.

- **SMPTE 마스터** — SMPTE OUT MASTER 레이어 뒤의 덱입니다. MASTER ← A 또는 B이면 그 레이어의 덱을 따라갑니다(기본). MASTER가 CLOCK이나 FREEWHEEL로 나가는 동안에는 CDJ 템포 마스터를 따라갑니다.
- **템포 마스터** — CDJ 마스터입니다.
- **온에어 덱 (자동)** — 지금 나가는 덱입니다. FLOW 레이아웃이 메인 덱을 고르는 방식처럼 재생 상태, 페이더, 남은 시간으로 고릅니다. DJ가 MASTER를 누르기 전에 바뀔 수 있습니다.

따라갈 덱이 없으면 "마스터 덱 없음", 곡이 셋리스트에 없으면 "셋리스트에 없는 곡", 곡에 큐가 없으면 "이 곡에는 큐가 없습니다."가 표시됩니다.

### 헤더

- **타임코드** — SMPTE OUT MASTER 타임코드입니다.
- **박 칸** — 네 칸입니다. 마디 안에서 지금 재생 중인 박이 켜지고, 첫 박은 주황색입니다.
- **BPM** — 따라가는 덱의 BPM입니다.
- **제목, 아티스트** — 따라가는 곡입니다. 레이어 바나 레인에 이미 표시되면 나오지 않습니다.
- **보드, 레이어** — 테마를 바꿉니다. 창 너비가 600px보다 좁으면 설정 팝업에 있습니다.
- **붙이기, 스피커, 톱니바퀴** — 창을 붙이거나 떼고, 음성 안내를 켜고 끄고, 설정 팝업을 엽니다.

### 테마

- **보드** — 위쪽 레이어 바에 레이어 A와 B의 덱 번호, 곡 제목, 재생 시간이 표시됩니다. M은 MASTER가 따라가는 레이어이고, 다른 레이어의 덱에는 다음 곡 표시가 붙습니다. 그 아래에는 그룹마다 타일이 하나씩 있습니다. 타일에는 그룹 이름, 다음 큐 이름, 큰 카운트다운, 마디.박, 진행 막대가 있고, 오른쪽 아래에 그 그룹의 이후 큐가 표시됩니다. 큐에 가까워지면 타일이 그룹 색으로 차오르고, 큐 순간에 GO가 뜹니다. 지금 곡에 큐가 없는 그룹은 작은 카드로 줄고, 큐가 있는 그룹이 남은 공간을 나눠 씁니다. 맨 아래 띠에는 다음 곡(다른 레이어의 덱)과 그 곡의 첫 큐들이 그 곡의 위치를 기준으로 한 시간과 함께 표시됩니다.
- **레이어** — 레인 세 개와 카운트다운 목록입니다. MASTER 레인에는 따라가는 덱의 파형이 왼쪽으로 흐르고, 표시 중인 그룹의 큐 마크와 이름이 함께 나옵니다. NOW 선은 폭의 20% 지점이고, 큐는 NOW에 닿는 순간 도달합니다. A, B 레인에는 각 SMPTE 레이어의 덱이 표시되며, 다른 레이어의 덱은 다음 곡으로 큐와 함께 나옵니다. 덱의 루프는 디테일 웨이브폼처럼 레인에 표시되고, 루프가 설정만 되고 꺼져 있으면 흐리게 표시됩니다. 비트 그리드는 [설정](#15-설정)의 **비트 그리드: 디테일**을 따릅니다. 아래 목록에는 다가오는 큐가 한 행씩 나오며 레이어, 이름, 남은 시간, 마디.박, 마지막 1분 동안 줄어드는 막대가 표시됩니다.

레이어 테마에서는 MASTER 레인 오른쪽 아래의 −로 곡을 더 넓게, +로 더 좁게 보고, RST로 자동 범위로 돌아갑니다. 레인 위에서 마우스 휠을 돌리거나 핀치해도 확대, 축소됩니다.

### 남은 시간

초와 박을 함께 표시합니다. 10초 미만이면 초를 0.1초 단위로(`4.3 s`), 10초 이상이면 분:초로(`0:24`) 표시합니다. 마디.박은 CDJ처럼 거꾸로 셉니다. `2.3 bar`는 2마디 3박 남았다는 뜻이고, 마디 안의 박은 4 3 2 1로 줄어듭니다.

큰 카운트다운(설정 팝업에서 고른 마지막 5, 10, 15, 30초)에 들어가면 마디.박 자리에 박 칸 네 개가 표시됩니다. 마지막 박은 3 2 1(또는 5, 10부터)로 세고 GO가 뜹니다. 숫자를 셀 때마다 해당 타일이나 행이 잠깐 밝아집니다. 진행 중인 긴 큐는 이름과 끝까지 남은 시간을 표시합니다.

### 설정 팝업 (톱니바퀴)

| 섹션 | 항목 |
| --- | --- |
| 표시 | 화면(보드, 레이어), 큰 카운트다운 시작(5, 10, 15, 30초), 마디.박과 박 칸 보이기, 박자 카운트 시작(3, 5, 10), 표시 그룹, 레인의 웨이브폼 색(곡 색 (CDJ), 회색, 끄기), 따라갈 덱(SMPTE 마스터, 템포 마스터, 온에어 덱 (자동)) |
| 웹뷰 | 폰이나 태블릿에서 열 주소와 **주소 복사**, **브라우저로 열기**. 설정의 웹 뷰어가 켜져 있어야 합니다. |
| 음성 안내 | 말하는 방식(이름+카운트, 이름만, 카운트만), 미리 알림(8박 전, 4박 전), 카운트다운(3, 2, 1, 없음), 마지막 말(GO, 없음), 목소리, 출력(장치, 채널, 볼륨, 들어 보기), 클릭(없음, 큐 콜 중, 항상)과 클릭 볼륨, 그룹별 스피커 |

표시 설정은 창마다 따로 저장되고, 따라갈 덱과 음성 안내 설정은 모든 창에 같이 적용됩니다. 볼륨은 200%까지 올릴 수 있습니다.

### 음성 안내

큐 콜 헤더의 스피커로 음성 안내를 켜고 끕니다. 시스템 목소리(macOS, Windows)로 문장을 미리 만들어 두고, 공연 중에는 박에 맞춰 재생합니다. 안내는 **따라갈 덱**에서 고른 덱을 따라갑니다.

- 큐 8박(또는 4박) 전에 "그룹, 큐 이름, 스탠바이", 마지막 세 박에 "셋, 둘, 하나", 큐 순간에 "고"를 말합니다. **말하는 방식**, **카운트다운**, **마지막 말**로 일부를 뺄 수 있습니다.
- **목소리** 목록은 언어별로 묶여 있습니다. 앱이 말할 수 있는 언어(한국어, 영어, 일본어, 스페인어, 독일어, 프랑스어, 중국어)의 목소리만 표시됩니다. 첫 항목 "시스템 ○○ 목소리"는 화면 언어의 기본 목소리입니다. 다른 언어의 목소리를 선택하면 안내도 그 언어로 바뀝니다(영어 목소리면 "Lighting, standby", "three, two, one, go"). 셋리스트에서 직접 지은 그룹 이름은 그대로 읽습니다.
- 그 언어의 목소리가 없으면 영어로 말하고 목록 첫 항목에 안내가 표시됩니다. 목소리는 운영체제의 음성 설정에서 추가할 수 있습니다.
- **출력**은 모든 안내에 쓰는 장치와 채널 하나입니다. LTC와 같은 오디오 장치의 다른 채널은 선택할 수 있지만, LTC가 사용하는 채널은 "LTC 사용 중"으로 표시되고 선택할 수 없습니다.
- **클릭**은 카운트하는 동안이나 항상 박마다 소리를 냅니다. 4박마다 첫 박은 높은 음으로 울립니다.
- 그룹 이름 옆 스피커로 그 그룹만 끕니다. 열려 있는 큐 콜에 표시된 그룹만 말하고, 큐 콜이 하나도 열려 있지 않으면 모든 그룹을 말합니다.

### 웹 페이지

설정의 웹 뷰어가 켜져 있으면 같은 네트워크의 폰, 태블릿, 다른 컴퓨터에서 `http://<이 컴퓨터 주소>:<포트>/cuecall`을 엽니다. 처음에는 접속 코드를 묻고(웹 뷰어와 같은 코드), 입력한 코드는 12시간 동안 유지됩니다. 이 컴퓨터에서 **브라우저로 열기**로 열면 코드를 묻지 않습니다. 페이지의 톱니바퀴에서 보드, 레이어 테마, 그룹, 큰 카운트다운, 박자 카운트, 마디.박 표시를 고르며, 이 설정은 그 브라우저에 저장됩니다. 브라우저가 지원하면 **화면 꺼짐 막기**로 화면이 꺼지지 않게 합니다. 폰 세로 화면에 맞춘 배치가 있습니다. ORVIK이 3초 동안 응답하지 않으면 페이지가 흐려지고 "연결 끊김"이 표시되며, 다시 응답할 때까지 카운트다운이 멈춥니다.

## 12. NETWORK

![NETWORK](images/16-network.png)

1. **PRO DJ LINK 상태** — PRO DJ LINK를 수신할 준비가 됐는지 나타냅니다. CDJ가 실제로 감지되는지는 기기 목록에서 확인합니다.
2. **기기 목록** — 확인된 CDJ와 DJM의 번호, 종류, 기종, IP 주소입니다.
3. **TCNet 상태** — TCNET 스위치의 켜짐 상태와 ORVIK의 노드 이름입니다.
4. **노드 목록** — ORVIK 자신과, 최근 10초 안에 확인된 TCNet 노드입니다.
5. **TYPE** — 노드 역할입니다. SERVER는 송신 측, CLIENT는 수신 측이며 REPEATER, AUTO도 있습니다. TCNet이 켜져 있는데 CLIENT가 하나도 없으면 목록 아래에 안내가 표시됩니다.

### 12.1 연결 구성 경고

![연결 구성 경고](images/16b-network-warning.png)

PRO DJ LINK가 켜져 있는 동안 ORVIK은 이 컴퓨터의 연결 상태를 확인합니다. 구성 문제로 플레이어와 믹서의 신호가 ORVIK에 닿지 않으면 NETWORK 위쪽에 원인과 해결 방법이 담긴 경고가 나타납니다. 상태 바에는 LINK로 표시되고, PRO DJ LINK 스위치의 툴팁에도 원인이 나옵니다. 빨간색은 링크가 전혀 동작할 수 없다는 뜻이고, 주황색은 권고입니다. 경고는 PRO DJ LINK가 시작되고 10초 뒤부터 표시되며 안내만 합니다. ORVIK은 네트워크 설정을 바꾸지 않습니다.

| 경고 | 나타나는 경우 | 해결 방법 |
| --- | --- | --- |
| 다른 프로그램이 PRO DJ LINK 포트를 쓰고 있습니다 | 다른 프로그램이 PRO DJ LINK 포트(50000~50002)를 쓰고 있습니다. ORVIK이 알아낼 수 있으면 프로그램 이름도 표시합니다. | 그 프로그램을 끈 다음 PRO DJ LINK를 껐다 켭니다. 흔한 원인은 rekordbox, 또 다른 ORVIK, AnyDesk, 통화 중인 Microsoft Teams, Beat Link Trigger 같은 PRO DJ LINK 도구입니다. |
| 기기가 다른 네트워크에 있습니다 | 플레이어나 믹서가 이 케이블로 신호를 보내지만 주소가 이 어댑터의 네트워크 밖에 있습니다(예: 기기는 자동 할당 주소 169.254.x.x이고 어댑터는 공유기 주소인 경우). | 어댑터를 자동으로 주소 받기(DHCP)로 바꾸거나 기기와 같은 대역의 주소를 주거나, 모든 기기를 같은 공유기에 연결합니다. |
| PRO DJ LINK 기기가 잡히지 않습니다 | 선택한 어댑터(Windows 자동 감지에서는 모든 어댑터)에 아무것도 들어오지 않았거나, 15초 동안 링크 수신이 끊겼습니다. | 플레이어와 믹서가 켜져 있는지, 케이블과 스위치, 주소 대역을 확인합니다. macOS: 시스템 설정 > 개인정보 보호 및 보안 > 로컬 네트워크에서 ORVIK을 허용합니다. Windows: 공유기 없이 연결한 어댑터는 공용 네트워크로 잡히므로 공용 네트워크에서도 ORVIK을 허용합니다. 켜져 있는 다른 어댑터가 목록으로 표시되므로 설정에서 맞는 어댑터를 고를 수 있습니다. |
| 두 어댑터가 같은 네트워크에 있습니다 | 이 컴퓨터의 어댑터 두 개가 같은 네트워크에 있어 곡 데이터와 파형 요청이 엉뚱한 어댑터로 나갈 수 있습니다. | 다른 어댑터를 끄거나 케이블을 뽑거나 다른 네트워크로 옮깁니다. |

## 13. OUTPUT

덱과 믹서 값을 OSC, DMX(Art-Net, sACN), MIDI로 다른 프로그램과 장비에 보냅니다. 이전 버전의 OSC 페이지와 ART-NET DMX 패치를 하나로 합친 노드 편집기입니다. 1.6에서 사용하던 OSC 행과 DMX 패치는 처음 실행할 때 노드로 옮겨지며 보내는 값은 같습니다.

![OUTPUT](images/17-output.png)

### 페이지 위쪽

- **되돌리기, 다시 실행** — 페이지의 변경을 되돌리고 다시 실행합니다. 되돌리기는 Ctrl+Z(맥은 Cmd+Z), 다시 실행은 Ctrl+Shift+Z 또는 Ctrl+Y(맥은 Cmd+Shift+Z)입니다.
- **IMPORT, EXPORT** — EXPORT는 페이지 전체(노드, DMX 출력, OSC 행, 네트워크 설정)를 파일로 저장합니다. IMPORT는 파일을 불러오며, 되돌리기 한 번으로 취소됩니다. 불러오는 파일이 송신을 켜는 경우에는 보낼 곳을 보여 주고 먼저 확인을 받습니다.
- **⋯** — **자동 저장 기록…**은 이전 노드 사본을 되돌립니다. [자동 저장](#자동-저장-기록)
- **OSC** — OSC를 보낼 곳(주소:포트) 또는 꺼짐을 표시합니다. 누르면 OSC 출력을 설정합니다. 켜기와 끄기, 보낼 곳(**이 컴퓨터**, **브로드캐스트**, **IP 주소**), IP와 포트(기본 7000)를 정합니다. **다른 OSC 대상 (큐 동작)**에는 큐 편집기의 OSC 동작에 쓸 주소를 이름을 붙여 둡니다. +로 추가하고 ×로 지웁니다.
- **Art-Net 네트워크** — 인터페이스와 DMX 빈도 또는 꺼짐을 표시합니다. 누르면 모든 DMX 출력이 같이 쓰는 설정이 나옵니다. **Art-Net 켜기 (타임코드, DMX 공통)**, DMX 인터페이스(타임코드 인터페이스를 따르게 할 수 있음), DMX 포트(6454), DMX 빈도(10~60Hz, 기본 40), 사용 중인 브로드캐스트 주소, ArtSync, ArtPollReply입니다. OSC 출력 포트는 Art-Net에 쓸 수 없습니다.
- **Art-Net 타임코드** — 프레임 레이트 또는 꺼짐을 표시합니다. 누르면 **타임코드 보내기**, 보내는 레이어와 지금 나가는 타임코드, 타임코드 인터페이스, 보낼 곳(브로드캐스트 또는 IP 주소 하나), 타임코드 포트가 나옵니다. **Art-Net 네트워크**에서 Art-Net이 켜져 있어야 합니다. 프레임 레이트는 [설정](#15-설정)의 SMPTE Timecode 출력에 있는 **Frame Rate**이고, 레이어별 켜기는 SMPTE OUT의 ART 버튼입니다.
- **MIDI** — MIDI CC, MIDI Note 노드가 쓰는 MIDI 출력입니다. 누르면 장치를 고릅니다. 설정의 MIDI Clock 출력에 있는 **MIDI 출력 포트**와 같은 포트입니다.
- **스캔** — Art-Net 장비(ArtPoll), OSC 프로그램(mDNS), MIDI 출력을 찾아 목록으로 보여 줍니다. Art-Net 장비 옆 +는 그 IP를 첫 번째 DMX 출력의 받는 장비에 추가하고, OSC 프로그램 옆 +는 다른 OSC 대상에 추가합니다.

### 가운데 캔버스와 오른쪽 설정

노드의 출력 점에서 다른 노드의 입력 점으로 드래그해 연결합니다. 선을 노드 위에 놓으면 가장 가까운 입력에 연결됩니다. 선 위에는 지금 흐르는 값이 보입니다. 값 하나를 여러 곳으로 보낼 수 있습니다. 연결선이 없는 변환 노드나 연산 노드를 선 위에 놓으면 그 선 사이에 끼워집니다. 문자 값(제목, 아티스트, 키)은 OSC로만 보낼 수 있습니다. DMX나 MIDI로 연결하면 연결되지 않고 이유가 표시됩니다.

- **선택** — 노드를 클릭합니다. 빈 캔버스를 드래그하면 여러 개를 고르고, Shift+클릭이나 Ctrl+클릭(맥은 Cmd+클릭)으로 하나씩 더하거나 뺍니다. Delete로 선택한 노드를 지웁니다.
- **우클릭 메뉴** — 잘라내기, 복사, 붙여넣기, 복제, 삭제, 연결선 끊기, 전체 선택, 그룹 만들기, 그룹 풀기가 있습니다. Ctrl+G(맥은 Cmd+G)로 고른 노드를 그룹으로 묶고, Shift를 함께 누르면 그룹을 풉니다. 그룹은 이름 띠를 잡고 끌어 옮기고, 이름 띠를 더블클릭하면 이름을 바꿉니다.
- **이동** — 노드는 다른 노드의 가장자리와 가운데에 맞춰 붙습니다. Alt를 누른 채 옮기면 자유롭게 놓을 수 있습니다. Space를 누른 채 드래그하면 화면을 옮깁니다. 터치스크린에서는 빈 캔버스를 손가락으로 끌어 화면을 옮기고, 손가락을 잠깐 멈췄다가 끌면 노드를 고릅니다.
- **문제 표시** — 보낼 수 없는 노드에는 이유가 표시됩니다. 연결 안 됨, 이 연결로는 보낼 수 없음, 채널이 겹침, 한도 초과, 순환 연결, 다른 DMX 출력이 이미 쓰는 유니버스입니다.

노드를 선택하면 오른쪽에 설정이 표시됩니다.

- **값 노드** — 값과 덱입니다. 덱은 마스터 덱 또는 덱 1~6입니다. Beat와 Phase는 박마다 1, 2, 4, 8, 16번 돌게 할 수 있고, Downbeat, BarBeat, BarPhase는 마디마다 여러 번(모양과 함께) 돌게 할 수 있습니다.
- **OSC** — 주소와 형식입니다. 문자 값은 string으로, 숫자는 float나 int로, 문자 형태도 있는 숫자(Time, Length, BPM 등)는 float, int, string으로 보냅니다. 값이 바뀔 때만 보내며 최대 60Hz입니다. 주소에 `/`가 없으면 붙이고, 공백과 `# * , ? [ ] { }`는 사용할 수 없습니다.
- **DMX 출력** — **이 유니버스 보내기**로 출력을 켭니다. **Art-Net 주소**는 Net(0~127), Subnet(0~15), Universe(0~15)이며, DMX 출력마다 유니버스가 달라야 합니다. **받는 장비 IP**에는 주소를 쉼표나 공백으로 나눠 적습니다. 비워 두면 첫 번째 DMX 출력은 ArtPoll로 찾은 장비로, 나머지는 Art-Net 네트워크의 브로드캐스트 주소로 보냅니다. 첫 번째 DMX 출력은 sACN으로도 보낼 수 있습니다(**sACN으로도 보내기**). 유니버스, 우선순위 같은 sACN 설정은 [설정](#15-설정)의 **sACN 출력**에 있습니다. 값을 **+ 채널**에 연결하면 다음 채널이 배정되고, 노드의 채널 번호를 클릭하면 바꿀 수 있습니다. 0~1 값을 0~255로 보냅니다.
- **MIDI CC, MIDI Note** — MIDI 채널(1~16)과 CC 번호 또는 노트 번호(0~127)입니다. 0~1 값을 0~127로 보냅니다.
- **범위** — 0~1 값을 **시작**~**끝**으로 변환합니다. 시작을 끝보다 크게 입력하면 거꾸로 움직입니다. BPM은 20~500 BPM을 0~1에 대응시킵니다.
- **모양** — 0~1 값을 sin, tri, saw, sq 파형으로 변환하며 반전 스위치가 있습니다. **반전**은 1−값입니다.
- **프리런** — 비트 값(Beat, Downbeat, Phase, BarBeat, BarPhase)을 덱의 템포로 스스로 진행시킵니다. CDJ의 비트 정보가 들어오는 사이에도, 비트 정보가 없어도 계속 진행합니다.
- **시간 형식** — 시간 값(Time, Length, Remain, SMPTE, Clock)의 필드(hh, mm, ss, ff)를 선택합니다. 아래 "시간 형식" 참고.
- **더하기, 빼기, 곱하기, 나누기, 최솟값, 최댓값** — 연결한 만큼 입력을 받습니다. 입력이 하나면 **두 번째 값**을 사용합니다. 페이더와 레벨은 0~1로, BPM과 개수는 숫자 그대로 계산합니다. **더하기**에 문자를 넣으면 이어 붙입니다("A" + "B" = "AB").
- **범위 제한** — 값을 **하한**과 **상한** 사이로 묶어 둡니다. **임계값**은 정한 값 이상이면 1, 아니면 0을 보냅니다.
- **부드럽게** — 값의 변화를 느리게 만듭니다. **어택 (ms)**은 값이 오를 때 따라가는 속도, **서스테인 (ms)**은 입력이 내려간 뒤 최고값을 유지하는 시간, **릴리즈 (ms)**는 그다음 내려가는 속도입니다. 클수록 느리고, 0이면 바로 따라갑니다. 이 세 설정이 생기기 전에 저장한 부드럽게 노드는 오를 때와 내릴 때 모두 기존의 시간 하나를 그대로 씁니다.
- **줄바꿈** — 문자열 값을 여러 줄로 잇습니다(예: 제목 / 아티스트).
- **정수, 실수, 문자** — 직접 입력하는 값입니다. 문자는 OSC로만 보낼 수 있습니다.

계산은 출력 엔진에서 하므로 다른 페이지를 보고 있어도 계속 송출됩니다.

### 값 이름과 보내는 값

범위를 지정하지 않았을 때 보내는 값입니다.

| 분류 | 이름 | 값 |
| --- | --- | --- |
| 믹서 채널별 (채널 1~6) | Fader, VU, Hi, Mid, LoMid, Low, Color | 0~1 |
| | OnAir | 온에어면 1, 아니면 0 |
| 믹서 전체 | Xf, MVU, MVUL, MVUR, BeatFX | 0~1 |
| | BeatFXOn | 비트 FX가 ON이면 1 |
| | BeatFXName, BeatFXCh, ColorFXName | 선택한 비트 FX 이름, 비트 FX를 건 채널, 컬러 FX 이름 (string) |
| 덱별과 마스터 덱 | BPM | BPM 그대로 (string이면 `128.0`처럼 소수 첫째 자리). BPMCoarse는 정수 부분, BPMFine은 소수 부분 |
| | Pos | 곡 진행 0~1 (string이면 `42%`) |
| | Beat, Downbeat | 비트마다 잠깐 1, 마디 첫 비트에만 잠깐 1 |
| | Phase | 비트 안의 위치 0~1 |
| | BarBeat | 마디 안에서 몇 번째 비트인지 1~4 |
| | BarPhase | 마디 안의 위치 0~1 (네 비트에 한 바퀴) |
| | Phrase | rekordbox 프레이즈 이름 (string, 예: `CHORUS`) |
| | PhraseKind | 프레이즈 번호: Intro 1, Verse 2, Bridge 3, Chorus 4, Up 5, Down 6, Outro 7 (프레이즈가 없으면 0) |
| | PhrasePos, PhraseBeats | 프레이즈 안의 위치 0~1, 다음 프레이즈까지 남은 비트 수 |
| | Loop, Sync | 루프 중이면 1, 싱크가 켜져 있으면 1 |
| | Title, Artist, Key | 곡 제목, 아티스트, 키 (string) |
| | Time, Length, Remain | 현재 시간, 전체 시간, 남은 시간 (string, `MM:SS`, 남은 시간은 `-MM:SS`) |
| 덱별만 | CDJPlay, CDJCue | 재생 중이면 1, CUE를 누르는 동안 1 |
| | Master | 그 덱이 CDJ 마스터면 1 |
| 마스터 덱만 | Deck | 마스터 덱의 플레이어 번호 1~6 |
| SMPTE, 시계 | SMPTEA, SMPTEB, SMPTEM | SMPTE OUT의 A, B, MASTER 레이어 타임코드, 도크에 표시되는 값 (string, `HH:MM:SS:FF`, 29.97 드롭 프레임은 `HH:MM:SS;FF`, 오프셋 포함) |
| | Clock | 컴퓨터 시각 (string, `HH:MM:SS`) |

- 마스터 덱은 헤더 MASTER BPM과 같은 덱입니다. CDJ 마스터가 없으면 재생 중인 덱을 사용하며 온에어인 덱을 우선합니다.
- Resolume 템포 주소(`/composition/tempocontroller/tempo`)로 보내는 BPM은 0~1(20~500 BPM)로 보냅니다. Resolume이 이 주소에서 0~1 값을 받기 때문입니다.
- 믹서가 없으면 믹서 값은 보내지 않습니다. 0을 보내면 페이더에 묶어 둔 레이어가 꺼지기 때문입니다. BPM이 없는 덱의 BPM도 보내지 않습니다.
- 켜고 끄는 값(OnAir, BeatFXOn, Loop, Sync, CDJPlay, CDJCue, Master)과 Deck은 string으로도 보낼 수 있습니다(`ON`, `OFF`, `2`).

### 시간 형식

시간 값에 시간 형식 노드를 연결하면 선택한 필드만 보냅니다.

| 글자 | 필드 |
| --- | --- |
| `hh`, `h` | 시 |
| `mm`, `m` | 분 |
| `ss`, `s` | 초 |
| `ff`, `f` | 프레임 (SMPTE만) |

두 글자로 쓰면 앞에 0을 붙여 두 자리로 보내고 한 글자로 쓰면 그대로 보냅니다. 여러 필드를 이어 쓰면 `:`로 이어 보냅니다(예: `mmss` → `05:08`, `hmmss` → `0:05:08`). 곡 시간은 `h`를 쓰지 않으면 분이 60을 넘어도 그대로 셉니다. Remain에 형식을 적용하면 `-` 없이 보냅니다. 29.97 드롭 프레임 타임코드는 프레임 앞을 `;`로 보냅니다.

## 14. SHORTCUT과 MAP

키보드, MIDI, OSC, DMX(Art-Net)로 ORVIK의 버튼을 누르고 값을 바꿉니다. 대상은 레이어 A, B, MASTER의 SMPTE OUT 조작과 헤더의 PRO DJ LINK, TCNET, M.VOL입니다. 수신 측만 설정하면 되고, 지정한 버튼의 켜짐과 꺼짐은 MIDI 장치로 돌려보낼 수 있습니다.

![SHORTCUT](images/19-shortcut.png)

### SHORTCUT 페이지

입력은 왼쪽에 있습니다. 입력마다 **활성** 스위치가 따로 있습니다.

| 섹션 | 내용 |
| --- | --- |
| 키보드 | ORVIK 창이 앞에 있을 때만 인식하는 키 조합입니다. 기본으로 켜져 있습니다. |
| MIDI | 연결된 모든 MIDI 장치가 **IN**(입력받기)과 **OUT**(지정한 버튼의 상태를 그 장치로 돌려보내기, 컨트롤러 LED용)과 함께 표시됩니다. 기본으로 켜져 있습니다. |
| OSC | OSC 수신 포트(기본 7700), 받는 곳(모든 인터페이스, 이 컴퓨터만, 인터페이스 하나), 보낼 수 있는 IP 목록입니다. 목록을 비우면 같은 망의 누구나 조작할 수 있으니 공연장에서는 IP를 적어 두세요. 기본으로 꺼져 있습니다. |
| DMX (Art-Net) | 조명 콘솔이 보내는 Art-Net 유니버스 하나(Net / Subnet / Universe)의 채널로 조작합니다. 보낼 수 있는 IP는 OSC와 같은 목록을 씁니다. 같은 컴퓨터의 Resolume과 함께 받으려면 콘솔에서 브로드캐스트로 보냅니다. 기본으로 꺼져 있습니다. |

페이지 오른쪽 위의 **MAP 켜기**를 누르면 DECKS로 이동하고 MAP이 켜집니다.

목록에는 모든 동작이 LAYER A, LAYER B, MASTER, 헤더로 묶여 표시됩니다. 소스와 오프셋 스텝 행은 펼치면 개별 동작이 나오고, 지정된 개수가 표시됩니다. **전체**는 모든 동작을, **지정된 것만**은 지정한 동작만 보여 줍니다.

- **키, MIDI, DMX** — 칸을 클릭한 뒤 키를 누르거나 MIDI, DMX를 보내면 지정됩니다. 그동안 칸에는 입력 대기가 표시됩니다.
- **MIDI 방식** — 지정된 MIDI 칸에 붙는 표시이며, 클릭하면 바뀝니다. 켜고 끄는 버튼: **Toggle**은 누를 때마다 켜고 끄고, **Piano**는 누르는 동안만 켭니다(127/0을 보내는 고정식 버튼에도 씁니다). 값: **Absolute**는 페이더나 노브 위치를 그대로 받고, **Relative**는 끝없이 도는 엔코더용으로 한 칸에 1%씩 움직입니다.
- **OUT** — 꺼짐과 켜짐 때 돌려보내는 MIDI 값입니다(기본 0과 127). APC mini mk2에서는 색 팔레트와 밝기, 깜빡임도 고를 수 있습니다.
- **OSC** — 동작마다 정해진 OSC 주소입니다. 예: `/orvik/smpte/a/ltc`. 클릭하면 복사됩니다.
- **×** — 그 행의 지정을 지웁니다.

창이 넓으면 오른쪽 패널에 **들어온 신호**(최근에 받은 입력과 그 결과)가 표시되고, OSC가 켜져 있으면 **OSC 받는 규칙**도 표시됩니다. 켜고 끄는 동작은 1이면 켜고 0이면 끄며, 값이 없으면 상태를 바꿉니다. 버튼은 값이 없거나 0이 아닌 값이면 누릅니다(0은 무시). 값은 0~1 float를 받습니다(0~100도 받음). 소스는 값으로도 받습니다(`/orvik/smpte/a/src 3`).

### MAP

사이드바의 MAP(또는 SHORTCUT 페이지의 **MAP 켜기**)을 누르면 지정 모드가 됩니다. MAP을 다시 누르거나 Esc를 누르면 나갑니다. 지정할 수 있는 버튼에는 테두리가 표시됩니다. 지정이 없으면 점선, 지정돼 있으면 실선과 칩(K 키, M MIDI, D DMX)이 표시됩니다. 버튼을 클릭하면 위쪽 바에 버튼 이름과 OSC 주소가 나옵니다(클릭하면 복사). 그다음 키를 누르거나 MIDI, DMX를 보내면 지정됩니다. **지우기**는 그 버튼의 지정을 지우고, **취소**는 입력 대기를 멈춥니다. OSC 주소는 정해져 있어 따로 지정하지 않아도 됩니다.

### 늘 동작하는 키

| 키 | 동작 |
| --- | --- |
| Ctrl+R(맥은 Cmd+R) | 화면을 다시 불러옵니다. 가상 덱 재생은 멈춥니다. |
| Ctrl+Z(맥은 Cmd+Z) | SET LIST와 OUTPUT에서 되돌리기(글자 입력 칸 밖에서) |
| Ctrl+Shift+Z 또는 Ctrl+Y(맥은 Cmd+Shift+Z) | 다시 실행 |
| Esc | MAP 나가기 |
| ⌘M (macOS) | 윈도우 > 최소화 |
| ⌘W (macOS) | 윈도우 > 닫기. 큐 콜 창을 닫고, 메인 창에서는 닫기 버튼처럼 ORVIK을 종료합니다. |

### SMPTE Timecode 출력

| 항목 | 설명 |
| --- | --- |
| Frame Rate | LTC, MTC, Art-Net 타임코드의 프레임 레이트입니다. 23.98, 24, 25, 29.97, 30fps 중에서 선택합니다. |
| 레이턴시 보정 | 타임코드에 더할 값(ms, −5000~5000)입니다. 양수면 앞서 나갑니다. LTC, MTC, Art-Net 공통이며 수신 측 지연을 맞출 때 사용합니다. |
| LTC: Layer A, LTC: Layer B, LTC: MASTER | 레이어마다 LTC를 출력할 오디오 장치(없음 또는 장치), 채널, 레벨입니다. 레벨은 −40~0dBFS이고 기본은 −12입니다. 노브를 더블클릭하면 기본값으로 돌아갑니다. 수신 측이 잡지 못하면 올리고, 소리가 찌그러지면 내립니다. |
| 정지 중 LTC 유지 | 덱이 멈추면 LTC가 멈춘 프레임을 계속 보냅니다. 수신 측이 바로 멈추고, 0으로 돌아간 덱은 00:00:00:00을 표시합니다. 끄면 멈춘 동안 LTC를 보내지 않습니다. 기본으로 켜져 있습니다. |
| MASTER 레이어가 마스터 덱 따라가기 | MASTER가 A, B를 따를 때, CDJ 마스터가 다른 레이어의 덱으로 바뀌면 MASTER도 그 레이어로 바꿉니다. 기본으로 켜져 있습니다. |
| 온에어 덱 유지, 멈추면 넘기기 | DJM이 있으면 MASTER는 온에어 덱(페이더를 올린 채 재생 중이거나 ON AIR인 덱)을 유지합니다. 그 덱이 멈추거나(0.5초) 페이더가 내려가면(2초) CDJ 마스터 덱이 온에어일 때는 그 덱으로, 아니면 다른 레이어의 온에어 덱으로 MASTER를 넘깁니다. 믹서가 없으면 MASTER는 MASTER 버튼을 따르고, MASTER 덱이 멈추면 0.5초 뒤 다른 레이어의 재생 중인 덱으로 넘깁니다. 끄면 MASTER 버튼만 따릅니다. 기본으로 켜져 있습니다. |
| 온에어 덱으로 고르기 (남은 시간 포함) | MASTER가 페이더, 재생 상태, 남은 시간으로 지금 나가는 덱을 고릅니다(FLOW 레이아웃이 메인 덱을 고르는 방식과 같습니다). 고른 덱은 5초 동안 유지합니다. DJ가 MASTER를 누르기 전에 바뀔 수 있습니다. 네트워크에 DJM이 있어야 하며, 없으면 MASTER는 MASTER 버튼을 따릅니다. 기본으로 꺼져 있습니다. |
| MTC MIDI 출력 | MTC를 보낼 MIDI 포트입니다. |
