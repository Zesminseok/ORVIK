덱 SMPTE 출력 출력 세트 리스트 믹서 큐 콜
Mac용 다운로드 Windows용 다운로드

CDJ와 DJM 데이터를 TCNet, SMPTE 타임코드, OSC, DMX, MIDI로 보냅니다.

Mac용 다운로드 Windows용 다운로드

버전 2.0.3, 무료 베타. Apple Silicon의 macOS 13.3 이상, Windows 10, 11.

링크의 모든 덱을 한 화면에.

링크에 연결된 모든 플레이어의 위치, BPM, 웨이브폼, 큐를 플레이어가 보내는 그대로.

타임코드로 내보내기.

레이어 A, B, MASTER의 LTC, MTC, Art-Net 타임코드.

모든 수신 장비로.

덱과 믹서 값을 OSC, Art-Net이나 sACN DMX, MIDI로 바꾸는 노드 편집기.

순간마다 큐 하나.

곡마다 타임코드 오프셋을 두고, 큐가 박에 맞춰 OSC, DMX, MIDI를 보냅니다.

믹서가 움직이는 그대로.

DJM이 알려 주는 페이더, EQ, FX, 레벨 미터. 화면은 DJM-900NXS2.

스태프 귀에 들리는 큐 콜.

그룹별 다음 큐와 남은 시간, 음성 안내, 같은 카운트다운을 폰에서 /cuecall로.

호환 장비와 환경

CDJ-3000X, CDJ-3000, CDJ-2000NXS2, DJM-V10, DJM-900NXS2

TCNet, LTC, MTC, Art-Net 타임코드, OSC, DMX(Art-Net, sACN), MIDI
받는 입력
키보드, MIDI, OSC(UDP 7700), Art-Net DMX(UDP 6454)

Apple Silicon의 macOS 13.3 이상, Windows 10, 11(x64)
