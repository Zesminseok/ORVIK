Sends CDJ and DJM data as TCNet, SMPTE timecode, OSC, DMX and MIDI.

Download for Mac Download for Windows

Version 2.0.2, free beta. macOS 13.3 or later on Apple Silicon, Windows 10 and 11.

From the decks to every receiver

Timecode, OSC, DMX and MIDI, each set up on its own page.

Cue calls the crew can hear

  • Next cue and time left, per group.
  • Spoken calls: standby, three, two, one, go.
  • The same countdown on a phone at /cuecall.

What it works with

Tested hardware
CDJ-3000X, CDJ-3000, CDJ-2000NXS2, DJM-V10, DJM-900NXS2
Sends
TCNet, LTC, MTC, Art-Net timecode, OSC, DMX (Art-Net, sACN), MIDI
Listens for
Keyboard, MIDI, OSC (UDP 7700), Art-Net DMX (UDP 6454)
Runs on
macOS 13.3+ on Apple Silicon, Windows 10 and 11 (x64)
Internet
No usage data. The update check asks GitHub with the app version and can be turned off.

Other hardware is untested so far. Results are welcome in Issues.
